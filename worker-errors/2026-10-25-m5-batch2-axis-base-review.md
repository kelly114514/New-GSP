# M5 第二批复审：轴上垂线/平行线的参数基

- 日期：2026-10-25
- 任务：M5 第二批坐标系交付（主 agent 为 Codex，型号未知；洁净室子 agent 型号未知），由 Claude Opus 5.5 复审
- 模型：Codex 主 agent（型号未知）
- 现象：首轮发现 15 在轴上的 200 px 参数基后，只给 15 加了特判，轴的直线几何仍然是坐标单位基 O→U。垂线 5、平行线 6 用 b−a 作基准向量，所以 107 个在轴上垂线/平行线上的 15 点位置错误。规格方预测器用了同一个假设，这些点预测不到 EMF 图元，被当作覆盖缺口排除，r4 报告“算错 0”。
- 原因：修 bug 时只修了出现症状的那一处，没有找同一个量的其它使用者；预测器和实现共用同一个未验证的假设，验收就失去了独立性。
- 处理：Opus 用 EMF 做两种假设的检验（7 个点只符合 200 px 基，0 个符合单位基），改卡片 58/59/60/61/5/6/15 和预测器；实现交洁净室 Sonnet 5.5 子 agent 修改，一次通过。r5 新增 31 条断言：原实现算错 31 条，修正后 0 条。
- 结论：一个基或单位规则被修正时，必须用 grep 列出它的所有读者（几何派生、参数化、变换）逐一核对。对排除数（`no_primitive_or_clipped` 等）在某类对象上异常集中的情况，要单独做 EMF 假设检验，不能只看“算错 0”。
