# M3 编辑器规格首稿把资料不足写成行为

- 日期：2026-10-24
- 任务：从手册与静态目录整理 M3 编辑器规格。
- 模型：GPT-6 Luna（high）
- 现象：首稿把多边形工具概括成约束 8；声称多点线段不闭合，与手册四点示例不符；还列了未经具体菜单项来源支持的泛化遗漏说明。首稿标有证据等级，但不足以防止这些具体错误。
- 原因：把工具模式与对象目录过早对应；概括手册时没有逐项核对示例；资源菜单提取只有顶层菜单，不能当完整构造子菜单清单。
- 处理：主 agent 抽查并要求有界自审。worker 删除不可靠的单一 ID 映射，修正闭合与 Shift 行为，逐项核对手册第三章的构造分组，补文本行号和未决项。最终规格仍是静态规格，未声称逐项实机验证。
- 结论：Luna 可做资料整理初稿，但菜单/选择顺序/产物映射必须逐项附来源，再由主 agent 抽查后交付。
