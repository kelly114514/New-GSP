# M2 参数方向的证据等级过强

- 日期：2026-10-23（America/Los_Angeles）。
- 任务：W1 交付基础几何对象卡片，供隔离的 W3 实现。
- 模型：Codex 当前会话继承模型；不是原交接记录中的 Sonnet/Haiku。
- 现象：首批线段卡片从 kind 2002 父序推断 t=0/1 的方向，并把整段基准说明标为已验证；基准 EMF 只证明线段集合和中点位置，不能证明参数方向。后续原版 HTML 出现反序，W1 自查后报告需要纠正。初版交点草稿也过早断言非法首选分支不会回退。
- 原因：把结构顺序和无向图元证据扩展成有向参数契约；推论的证据等级没有单独标记。
- 处理：主 agent 通知 W3 暂停依赖方向的新逻辑，保留已通过的无向线段/中点验收。W1 随后直接量测了 155 个线段、7 个直线、13 个射线上的非对称参数点，全部确认原生参数按 2002 同序，反序零匹配。因此修正的是证据等级和导出解释，不是把原生父表反过来；HTML 的端点反序不能用于推断原生求值方向。最终测量结论写入卡片后再同步实现。
- 结论：分批交付仍可用，但父序、参数零点、尺度和根选择必须各有独立证据；不能用“基准图形看起来一致”替代有向参数验证。
