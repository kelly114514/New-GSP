# Worker 错误记录

多 agent 协作时，worker 出错由主 agent 检查后记在这里，用来积累“什么任务交给哪个模型”的经验。记录实际使用的模型；历史模型建议不限制当前可用模型。

## 规则

- 每次出错一个文件，命名 `YYYY-MM-DD-<任务简称>.md`。
- 只记真实发生的问题：交付物错误、漏做、违反规则（如实现方读了禁读目录）、反复失败需要介入。worker 自己在过程中发现并改掉的小问题不记。
- 文件内容按下面的模板写，最后一行给出对模型选择的结论。

```markdown
# <任务简称>

- 日期：
- 任务：<一句话>
- 模型：实际模型名（未知时明确未知，不推测）
- 现象：<交付了什么、错在哪>
- 原因：<判断的根因：理解偏差 / 能力不足 / 指令不清 / 环境问题>
- 处理：<主 agent 直接修 / 重派给哪个模型 / 改指令后重派>
- 结论：<这类任务以后用哪个模型，指令要补什么>
```
