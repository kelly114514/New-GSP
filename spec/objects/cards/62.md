# 62 — 动作按钮族

## 身份：不是函数

约束外部 ID 62，主类 10；**存档 2000 中的 genera 外部 ID 是 23**。目录 `catalog.json` 的 `genera:20` 是 genera 表内索引：taxonomy 第 20 行映射到外部 ID 23。全语料 14,312 个对象/993 文件的实际头都是 `(62,10,23)`。不能把目录索引 20 直接作为读取器的头识别条件。

本类是动作按钮，含隐藏/显示、移动、动画、系列、滚动、声音等子形式，不是约束 0/main11/genera57 的函数定义，也不是计算 48。按钮可以引用函数作为操作目标（如播放声音），但按钮自身不产生数值，不可作为 48 的可调用父。

本批只交付身份与存储规格；执行按钮、编辑按钮、画布交互和新建写出属于后续按钮里程碑。**按钮行为的原版直接断言数：0**，不能称为已实现或已动态验证。

## 无损、存在性与后续实验

本批读取可呈现为带原记录的未支持动作对象；既不输出 `measurement`，也不生成点/线几何。不得因为目标是隐藏/未实现对象而丢掉按钮、改父表或删除 2003。读入再保存不改记录顺序、按钮块、名称、字体及父引用。

后续需经用户授权再做原版实验：分别创建隐藏/显示/切换按钮，单独切换一次选项并差分；动画单目标/多目标与方向速度；移动目标的对应顺序；系列的按序/同时与延迟；滚动目标；单/双函数声音。每类记录保存、重开、执行前后的可观察状态，并明确断言数。在这些实验完成前，不输出猜测的执行结果。

离线库存与代表字节由 `tools/m5_functions_evidence.py` 写到本机 `oracle/m5-batch3-functions/evidence.json`。它不启动原版，不调用产品实现，也不生成按钮行为期望。
