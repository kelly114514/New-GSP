# 28 — 按标记角（三点）绕中心旋转

像的头随源而定：点 622、射线/线段 163、多边形边界 53 等。981 个对象（149 个文件），五父：`[源 B,中心 C,p1,p2,p3]`，p1、p2、p3 定义「∠p1 p2 p3」（p2 为顶点）；父模板 `[88,95,4,0]`（数量码展开成五个父）。资源描述：「A 是 B 关于中心 C 旋转角度为 ∠p1p2p3 的旋转结果」；HTML `Rotation/MarkedAngle`（五个引用）。**无 kind 2003**。

## 定义

旋转角 θ = 页面上看起来**逆时针**从射线 p2→p1 转到射线 p2→p3 的角，取模 360°（顺时针的角等价于对应的负角）：

```
θ = (atan2_page(p1−p2) − atan2_page(p3−p2)) mod 360°,   atan2_page = atan2(dy, dx) 页面坐标（y 向下）
```

随后按 [27.md](27.md) 的公式绕 C 旋转 θ。手册也说明：按「边上的点、顶点、边上的点」逆时针选点标记的是正角，顺时针是负角。〔已验证：数值〕

证据：可见且唯一匹配 EMF 的对象 156 个（点 137、线段 13、多边形 6），156 个对象涉及 51 个文件，其中 `sin θ≠0` 的 51 个，θ 取值正负均有（约 −74° 到 +65°）；反号时这些对象失配。3 个点未对上，在深层链文件里。p1p2、p2p3 长度为 0（角无定义）时像不存在〔推测〕。其余见 [27.md](27.md)。
