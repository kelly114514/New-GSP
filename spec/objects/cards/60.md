# 60 — 单位圆定义的坐标轴

〔结构〕主类9/genera38；父 [圆 C]（可为变换后的圆）；2309格式同58。

〔已验证：原版 EMF/HTML 数值〕O=C.center，L=C.radius；坐标单位基：方向1为(L,0)，方向0为(0,−L)，输出在 `axis.origin=O`、`axis.unit`。坐标单位为圆半径，不直接受10041/10042影响。12次读数祖先核对属于间接证据，直接断言另列。

直线几何沿用58的写法 `a=O−100·e`、`b=O+100·e`，但**原生参数基没有原版证据，`parameterizationKnown:false`**：其上的15、以它为父的5/6的参数化都报未支持（直线点集本身可用）。

〔未知〕零半径、非圆父、未知方向/记录必须报未支持。刻度/网格与反向拖动未验收。

父不存在传播 not-existing；父未实现传播 unsupported / parent:N:unsupported。未核证边界必须报 unsupported 并说明原因；原记录无损保留。数值显示沿用 [数值契约](../../acceptance/m5-measures.md)，证据命令和样本数见 [本批报告 §2–3](../../acceptance/m5-batch2.md)。
