# 48 — 计算

主类11；genera随结果量纲变化，常见51（无单位）、48（长度）、49（角度）、50（面积），不能按约束48写死类型。49,419个对象，是本批优先实现的数值来源。父表2002是表达式引用的对象槽，按原生顺序读取；父可以是度量、参数、另一个计算或函数。

## 存储与引用

表达式在2311里保存为**u16中缀token**，不是UTF-8字符串，也不是HTML的RPN。共同显示前缀32字节；+36 u32恒等于载荷长−32；+40 u32为48；+44 u16是token个数N；+46 u16在全语料恒为4（具体名称未知）；+48..91保留；+92开始N个u16，载荷长92+2N。49,419个本类载荷全部满足。`+48..91`中有残留/过程态数据，不能清零或当数值常量使用。详见格式规格§8.11。

| token | 含义 |
|---|---|
| 0..9 | 数字字符0..9；相邻数字组成一个数 |
| 10 | 小数点 |
| 11 / 12 | 左括号 / 右括号 |
| 13 / 14 | π / e 常数 |
| 0x1000..0x1004 | 加、减、乘、除、幂；减号在操作数位置表示一元负号 |
| 0x2000..0x200C | 依次sin,cos,tan,asin,acos,atan,abs,sqrt,ln,log,sgn,round,trunc；函数token自带左括号，末尾由12关闭 |
| 0x6000+i | 当前对象2002父表的第i槽（0起）；不是全页对象编号 |
| 0x7000+i | 调用第i父函数，后跟实参及右括号12；本批不要求实现函数对象，明确报未支持 |
| 0x0100 / 0x0101 | 显式弧度 / 度单位后缀 |
| 0x0201 | 显式厘米后缀 |

0x0102（方向度）、0x0200（像素）、0x0202（英寸）属于单位token族的静态候选，未在本批独立核对，读入时保留；不得凭猜测吞掉其它token（方程成分等后续类型仍存在）。

例：`[0x6000,0x1003,2]`是`parent[0]/2`；`[3,10,5,0x1002,0x6000]`是`3.5*parent[0]`；`[0x200C,0x6000,12]`是`trunc(parent[0])`。HTML会将它们分别输出为`A 2 /`、`3.5 A *`、`A @trnc`。换成父槽1或交换除法左右不能得到同一表达式，绑定时必须比较有序父表及非交换运算结构。

## 数学语义与量纲

通常优先级为括号/函数、幂、乘除、加减；一元负号与幂结合、连续幂的结合方向仅有静态数学解释，本批未用原版边界输入实验确认，不得将研究解析器的一种实现当成最终证据。基础单层四则和显式括号已由HTML非交换表达式核对。

引用父值应取未舍入值。显式`360度`转换成2π弧度，`4厘米`转换成4*96/2.54页面px；HTML中相同项分别写为6.28319和151.181，仅有约6位有效数字，不代表原生只存这些小数。`sin/cos/tan`用弧度角；反三角输出角；abs为绝对值、sqrt为算术平方根、ln/log为自然/常用对数、sgn按正/零/负返回1/0/−1。round(x)按手册相当于floor(x+0.5)，trunc向零截断。Java导出trunc使用floor，不能移植为原生规则。

**本批实现的量纲表**（`number` 无单位、`length` 页面 px、`angle` 弧度、`area` 页面 px²；内部值一律用这四种基准单位，显示时才换算）：

| 构造 | 允许的量纲 | 结果量纲 |
|---|---|---|
| 数字字面量 | — | number |
| 数字字面量 + `0x0100`/`0x0101` | — | angle（值乘 1 / π÷180） |
| 数字字面量 + `0x0201` | — | length（值乘 96÷2.54） |
| `+` `-` | 两侧相同 | 两侧的量纲 |
| `*` | number×任意、length×length | 任意 / area（angle×angle、area×length 等一律未支持） |
| `/` | number 分母、同量纲、area÷length | 保留被除数 / number / length |
| `^` | 指数必须 number；底数 number，或底数 length 且指数 2 | number / area（其余幂未支持） |
| `sin cos tan` | number 或 angle | number |
| `asin acos atan` | number | angle |
| `abs` | 任意 | 同操作数 |
| `sqrt` | number、area | number / length（手册：sqrt(4平方厘米)=2厘米） |
| `ln log` | number | number |
| `sgn round trunc` | 任意 | number / 保留操作数（round 用 floor(x+0.5)，trunc 向零） |

上表之外的单位组合、单位 token 落在非字面量上、`0x0102`/`0x0200`/`0x0202`、`0x7000+i` 函数调用、任何未列 token，一律**显式未支持**，不得猜一个数。手册说 `(4平方厘米)^0.5` 得到无单位 2，这与 `sqrt` 不同；本批不实现该幂。

**父槽可以引用什么**：数值自由对象（[0.md](0.md) 的约束0/主类11，值取它自己的 2311；genera 57 的函数定义除外）、本批度量 36–47、其它计算 48。父槽指向没有数值的对象（如几何点、线段）时报未支持，不做隐式换算。

**结果量纲与对象头 genera 的交叉核对**（〔已验证：语料结构〕）：对象头 genera 与结果量纲在本批对象上一致——51↔number、48↔length、49↔angle、50↔area。实现应按自己的求值量纲核对这个字段；不一致时**不要**用 genera 覆盖算出的值，把不一致作为诊断上报（它说明量纲规则或父槽绑定有问题）。

单位算术不能简单套通用物理量系统：手册说明sqrt(4平方厘米)得到2厘米，但(4平方厘米)^0.5得到无单位2。不同量纲组合、幂和单位消去的完整规则尚未动态验证，本批先实现已证实的量纲相容算式；不支持的单位组合必须显式保留未支持。不要把屏幕数值直接代入长度/角度变换。

手册说明1/0为∞、−1/0为−∞、0/0和sqrt(−1)未定义、0^0为1。因此数学非有限值、几何不存在、表达式语法/类型未支持应分开记录；有∞的表达式不是读档失败，且下游几何仍需检查参数是否可用。本批十进制期望不覆盖∞和π分数。
