# 16 — 按标记向量平移

头：主类22 / genera92 起，**像的主类/genera 随源而定**（见 [通用契约](README.md)）。26,882 个对象（820 个文件），全三父：`[源 B,向量起点 P,向量终点 Q]`，父模板 `[88,95,4,0]`；P、Q 是点（自由点、路径点、交点、其它变换像等）。无 kind 2003 或类专有 23xx。资源描述：「A 是 B 通过向量 c→d 的平移结果」；原版 HTML 步骤 `VectorTranslation(源,P,Q)`。〔已验证〕

## 定义

`p′ = p + (Q − P)`，页面坐标。向量由父 P、Q 的当前位置给出，不记录在文件里。源可以是点、线段、射线、直线、圆、弧、扇形、弓形、多边形边界、内部、图片：像的几何是源几何整体按同一向量平移；圆像半径不变，弧像扫角不变。〔已验证〕

## 证据

可见且唯一匹配原版 EMF 图元的对象：点 451、线段 400、圆 62、多边形 12、弧 1、扇形 2、圆内部 1（共 929），最大误差 ≤0.1 页面像素；未对上的 43 个中 32 个点、4 条线段、5 个多边形在深层链或平移拟合不可靠的文件里（父点被剪裁出 EMF 或偏移是「得分拟合」），2 条射线因匹配器不支持射线，没有给出任何反例。向量为 0（P=Q）时的存在性〔未知〕。

## 其它

父不存在或 P、Q 任一不存在时像不存在。像不可直接拖动，拖动源或向量端点后重算；直接拖动像时的反向行为〔未知〕。样式与标签见 [通用契约](README.md)。
