# 4 — 圆心与半径的圆

头：主类 3 / genera 28。父：`[点 C,长度提供者 R]`，1,792 个对象全两父。父模板 `[4,77,0]`；第二父可以是线段，也可以是带长度单位的参数/度量，不得把第二父一律读成圆周点。实际第二父主类分布含 1、2、7、11：主类1的线段 genera 是工具占位，需先绑定。〔已验证：结构；长度语义静态证据〕

圆心为 C；R 为线段时 `r=|B-A|`，R 为长度值时先按该值所属单位转成页面长度。M2 只要求线段半径且祖先可求值的情况；参数/度量的单位换算须等其规格，当前不得直接把“厘米数”当像素。〔静态证据〕

父不存在或长度提供者无效则圆不存在。零/负半径的原版边界处理〔未知〕。无 kind 2003、2201 或类专有 23xx。拖动上游自由点后更新；样式和标签见 [通用契约](README.md)。
