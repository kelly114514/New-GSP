# 81 — 过三点的弧

头：主类12 / genera67。463 个对象，全三父：`[点 A,点 M,点 B]`，从A经过M到B；父模板 `[95,4,0]`。无 kind 2003 或类专有 23xx。〔已验证：结构；角色静态证据〕

不共线的三个点确定唯一支撑圆；弧从A到B且经过中间父M。选择圆周上包含M的那一段，不能不看M就一律取短弧。三点顺序参与弧身份，不能将它们按坐标排序。〔静态证据〕

父不存在或A=B时无有效起终路径。**共线不能一律判不存在：原生静态逻辑允许三点弧退化成A到B的线段**，中间点M的位置参与其有效性判断；当计算出的半径或圆心坐标超过约30,000页面单位，也切入线段分支。具体分界与符号规则尚待核对，不能用任意“很大半径圆”替代。该退化弧仍可能被11–14作为直线型参与求交。〔静态证据，尚未原版实验〕

本轮尚未以原版EMF核对有向扫角表示，求得经过M的几何集合后应保留方向待核对项。交点和路径点检查同 [79.md](79.md)。自由父拖动后重算；样式与标签见 [通用契约](README.md)。
