# 18 — 水平位移固定、垂直位移取自数值父的平移

像的头随源而定。149 个对象（26 个文件），两父：`[源 B,垂直位移值 c]`；父模板 `[88,95,43,0]`；c 是度量值（长度/距离度量，多为 (36,mk7)），也有 (48,mk11) 参数。资源描述：「A 是 B 通过水平移动 ^1 和垂直移动 ^c 的平移结果」。

## kind 2003（28 字节）

```
+0  u32 = 18
+4  f64 dx_px      水平位移像素（正向右）
+12 f64 dx_value   同一位移的单位数值
+20 u32 unit       0=像素 1=厘米 2=英寸
```

语料 149 个全部是 (0, 0, unit 1)：固定的水平位移恒为 0。〔已验证：布局；语义静态证据〕

## 定义与证据

`p′ = p + (dx_px, −Dy_px)`，Dy 为父 c 的当前值换算成像素（度量值的长度单位乘以 37.7953 px/cm，单位随度量；符号约定同 17：正向上）。**本类依赖度量/参数值（D 组），M2 之前无法数值核对，没有可见匹配证据**；符号和单位换算按 [17.md](17.md) 与 [通用契约](README.md) 类推，〔静态证据，M5 用 36/37 度量做验收〕。父不存在或值非有限时像不存在。
