# 11 — 直线型与圆/弧的交点，分支一

头：主类1 / genera45。3,757 个对象，全两父：`[直线型 L,圆型 C]`；圆型包括圆（主类3）和弧（主类12），还有工具区圆占位。父模板 `[7,8,0]`。无 kind 2003、2201 或类专有 23xx。〔已验证〕

先解支撑直线 `X=A+t d` 与支撑圆 `|X−O|²=r²`。令 `a=d·d`、`b=2d·(A−O)`、`c=|A−O|²−r²`，判别式 `D=b²−4ac`；D<0 无实交，D=0 为相切，D>0 两候选。再检查 L 的线段/射线范围，以及 C 为弧时的弧范围。〔静态证据〕

圆父为真正圆（未发生弧退化）时，**11首选L参数t较小的根，12首选较大的根**。原生静态辅助逻辑先按t排序，再检查对应根的线段/射线范围；首选求交失败时外层再尝试另一根。只有一个合法候选时两ID可能得到同一点，但存储身份仍不同。不能按x/y排序或最近旧屏幕位置选择根。〔静态证据〕

弧父还有方向符号参与首选根选择；顺向圆弧与反向三点弧的分支符号不能简单沿用上述真正圆规则，退化弧会转入直线型求交。相切时原生有约0.0002页面单位的半径容差、端点附近有约0.00005页面单位量级的范围容差；这些静态数值未以原版交互验证，不用于放宽普通几何验收0.1px以外的误差。

父不存在、支撑几何退化、D<0或本分支在范围外时不存在。与 [12.md](12.md) 共用求交，但存储身份不同。自由父拖动后重算本分支；样式与标签见 [通用契约](README.md)。
