# M2 基础几何对象卡片

本目录是实现方可读的行为契约。日期：2026-10-23。外部约束 ID 与文件 kind 分开书写；例如“约束 15 的 kind 2003”。

证据分为〔已验证〕（原版导出或全语料检验）、〔静态证据〕（对象描述、手册或组件语义）、〔推测〕与〔未知〕。数学定义有静态证据而边界未验证时，正常输入可以实现，边界必须保留为待验收项。不能因为有卡片就宣称该约束在全语料通过。

## 通用契约

- 坐标为页面坐标，x 向右、y 向下。自由点用 kind 2201 的两个 f64；显示坐标可整体平移，不得把导出图的平移写回几何。基准样本的坐标已由原版存档确认；其它 oracle 显示平移由验收工具处理。〔已验证〕
- kind 2002 的父序列有意义，1 起，父在子之前，允许重复。不要按类型排序或去重。〔已验证〕
- catalog 的主类/genera 是静态表内部编号；对象头 +6/+8 是外部编号。**不能拿 catalog.genera 直接和对象头 genera 相比。**例如圆的表内 genera 为 22，实际头为 28；弧为 24 / 67。全语料统计已核对。
- 正常页面里先求父，再求子。父不存在时子不存在，恢复父的有效状态后重新求子；隐藏与不存在分开，隐藏父仍参与求值。〔静态证据〕
- `不存在`、`未支持`、`工具输入尚未绑定`必须分开。工具容器内有以约束 0 / 主类 1 保存、genera 却声明线/圆等能力的输入占位；不能把这些占位点当真正线段求中点。〔已验证：语料形态；占位用途为静态证据〕
- 卡片所列不存在条件是数学条件，原版使用的精确浮点阈值〔未知〕。M2 可采用尺度相关容差；不得把很远的交点当平行，不得只用固定像素容差判相切。
- 直接移动自由点修改 kind 2201 并重算后代。约束点保持自己的约束；对其拖动不能改成自由点。路径点见 [15.md](15.md)。拖动其它构造物如何反向移动可动祖先属于交互策略，尚无原版实验，不由本批卡片虚构。M2 的必验收项是自由点拖动及传播。

## 样式、可见性和标签

所有卡片共享本节：颜色来自对象头 +12..14 RGB；比例值与未知字段必须原样保留；标签来自可选 kind 2005、样式引用来自 kind 2008（见格式规格 §8）。不要按约束 ID 写死颜色。

原版baseline的EMF+已独立量测以下外观（600dpi导出换成96dpi页面像素），属于〔已验证〕：

| 对象与样式 | 填充 | 外描边 |
|---|---|---|
| 自由点、中点，0x0221 | RGB(255,0,0)的圆，直径8页面px（半径4） | 黑色，线宽1.25页面px |
| 线段，0x0122 | 无 | RGB(0,0,128)，线宽3页面px |

点是FillEllipse与DrawEllipse两图元的叠加，不能只画无边框红圆，也不能用半径3替代。线宽随页面坐标变换缩放；不要直接拿600dpi导出数当屏幕像素。这组测量只验证上述样式，不足以外推所有w0/w2枚举。

三个样式字段当前只确认存储拆位。线类 w1=2/1/0 对应实/虚/点线、w0 控制线宽、点 w2 控制大小是待与 HTML/EMF 系统核对的候选，不能标作原版实验结论。布局 4 的换算仍按格式规格。隐藏状态码 0..4 的全部意义尚未定，不可把 `status != 0` 一律隐藏。kind 9006 的存在也不能单独当隐藏标志。

kind 2005 的文字区以 +22 的 u16 字节数、+24 文字读取；f[3]/f[4] 应按有符号 i16 保存。文本偏移、自动命名标志、可见标签开关的语义尚待核对。**没有 2005 的对象不得强行显示自动字母标签。**标签不能作为对象身份或父引用。新建对象的默认标签/样式写出留给 M3；M2 优先忠实读入。

## 变换（C 组）通用契约

C 组 = 外部约束 16–34、75、117–119，卡片见文末表格。以下对所有变换类型成立，各卡片只写差异。证据来源：全语料 2003 载荷统计、原版 HTML 构造文本里重复写出的参数、与原版 EMF 图元的逐对象数值对照（`tools/emf_match.py` 的 `predict()`，只用来选图元，期望值从 EMF 量得）。

- **父序**：`parents[0]` 是被变换的对象（源），其余父是变换参数（中心、向量端点、角的三点、镜面、比例/距离/角度的数值父）。同一约束的像可以是点、线段、射线、直线、圆、弧、扇形、弓形、多边形边界、多边形/圆内部、图片，类型与源保持一致。〔已验证：语料中 mainKind/genera 与源一一对应，见下表〕
- **像的头**：点的像是主类1 / genera4（与自由点同 genera，**不要据此当自由点**，也不要因为源是路径点就改成 genera10）；线段 2/14、射线 2/13、直线 2/12、圆 3/28、弧 12/67、扇形 13/68、弓形 13/69、多边形边界 4/52–55 或 4/15、内部 5/16、图片 16/78；少量点的像带 genera 63/89/92（源是特殊点）。〔已验证：语料统计〕
- **可变换的源**：点（含自由点、中点、交点、路径点、其它变换像）；线段、射线、直线（含垂线、平行线等线型）；圆；弧；扇形、弓形；多边形（顶点逐个变换）；圆内部；图片。源本身也可以是同一约束的像（链式变换在语料里大量出现）。〔已验证：存在性；图元数值对照覆盖的像见各卡〕
- **数学形式**：页面坐标（x 向右、y 向下）下，像为 `p′ = M·p + t`，`M` 是 2×2 相似矩阵（旋转/缩放/反射的组合）。圆像：圆心做同样变换，半径乘以 `|det M|^½`。弧像：圆心与第一端点做同样变换，扫角乘以 `sign(det M)`（**反射使弧的方向翻转**，旋转/平移/缩放不翻转，负缩放比是旋转 180° 加缩放，不翻转）。扇形、弓形跟随父弧。多边形边界保持顶点序。〔已验证：点、线段、圆、多边形、扇形、弓形；弧像的反射仅 5 例〕
- **角度**：本组所有「角」的正方向是页面上**看起来逆时针**（数学逆时针，页面 y 向下），与弧的扫角方向（见 [79.md](79.md)）一致。〔已验证：27、28、21，反例为 0〕
- **长度与单位码**：存档里的距离型参数同时存「页面像素」和「按单位表示的数值」，单位码 0=像素、1=厘米（1 cm=96/2.54≈37.7953 px）、2=英寸（96 px）；角度参数的单位码 0=弧度、1 与 2=度（两种度制，几何上等价，差别〔未知〕）。**几何使用像素字段和与单位无关的方向对**（见各卡），单位码只用于显示/编辑。全语料 34,298 个 21/24/27 载荷中，数值与方向对逐一自洽，17/18/19/21/22/23 的像素与数值比恒等于单位换算因子。〔已验证〕
- **存在性**：源不存在、任何参数父不存在、或参数无定义（反射的镜面退化成点，缩放比由距离比给出但分母为 0，角由零长度边定义）时，像不存在，恢复后重新求值；隐藏的父仍参与求值。参数值本身为 0（平移 0、旋转 0°、比例 1 或 0）时像仍然存在〔推测〕：语料里存在比例 1、旋转 0° 的对象并被原版绘制，缩放比 0 的像〔未知〕。
- **拖动**：变换的点像、线像都不是自由对象，位置完全由源和参数决定。像上的路径点（15）可拖动，参数保持（见 [15.md](15.md)）。直接拖动像对象时原版是否反向移动源〔未知，无原版实验〕；M4 的必验收项是拖动可动祖先后像随之更新。
- **HTML 对照**：原版 HTML 构造文本里变换步骤形如 `Rotation(源,中心,弧度)`、`Dilation(源,中心,比)`、`Translation(源,dx,dy)`；这些数字与存档 2003 逐个自洽（见各卡），可用来交叉检查参数解码，但**HTML 的参数次序和 y 轴符号不一定同原生**（平移的 dy 是 y 向上）。
- **证据口径**：下表「可见匹配」指状态码为 0（可见）、颜色一致、唯一匹配原版 EMF 图元的对象；状态码 1–4 的对象 HTML 都标 hidden（全语料 13,132 个绑定对象无例外）因而没有 EMF 图元，不计入。射线、直线的像在 EMF 里是被页面剪裁的长线，M2 匹配器暂未断言，标「未验证」。

## 证据与复查

全语料结构统计：1,431 文件、400,744 对象，由 `tools/m2_specs_evidence.py` 离线重跑，详细本机结果在 `oracle/m2_specs/evidence.json`，不入库。卡片的主类、genera、父签名计数与参数尺寸均来自此轮统计；语料例名相对原版样本目录，仅作为本机验收定位，不复制原文档。

语义来源为已生成的对象目录、使用手册的构造/点值章节及既有组件语义整理。手册不是一次新的原版操作实验；依赖手册的方向和拖动结论标〔静态证据〕。未启动原版。本轮会继续补充交点分支、圆/多边形路径参数和弧的证据。
