# 3 — 圆心与圆周点的圆

头：主类3 / genera28（catalog表内genera22）。2002父表：`[点 C,点 Q]`，6,266个对象全两父。第一个是圆心，第二个是圆周点，**本约束不采用2/63/64的反序规则**。唯一原生/HTML父图绑定170例全同序；另有106个自由点相对位置唯一匹配全同序；61条原版EMF圆心/半径匹配确认第一父为圆心。无kind2003或类专有23xx。〔已验证〕

圆心 C，半径 `r=|Q-C|`；圆上集合为 `|X-C|=r`。任一父不存在则圆不存在。r=0 时原版是否当作零半径圆，还是判不存在，尚未实测；依赖半径作除数的后代必须处理退化。〔静态证据；零半径边界未知〕

圆周点 Q 的角度不会重新定义圆的零参数方向；路径点的圆参数使用页面右向水平轴，见 [15.md](15.md)。M2 拖动 C 或 Q 时重算；圆整体拖动的反向传播未验。外观及标签见 [通用契约](README.md)。
