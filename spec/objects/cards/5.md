# 5 — 过点的垂线

头：主类 2 / genera 47（表内 genera42）。父：`[点 P,直线型对象 L]`，8,233 个对象全两父；父模板 `[4,7,0]`。L 可是线段、射线、直线、垂线、平行线、角平分射线及坐标轴；实际也有工具线占位。不能要求 L 的约束 ID 恰为 63。〔已验证：父形态；语义静态证据〕

L 有基准方向 `d=(dx,dy)` 时，结果是过 P 的无限直线，方向与 d 正交。L 的有限线段/射线范围不限制构造出的垂线。父不存在或 `|d|=0` 时结果不能确定。〔静态证据〕

原生静态求值已确认路径基准：设L的原生基准向量为 `d=B−A=(dx,dy)`，取页面向量 `n=(−dy,dx)`，结果的两个基准点为 `A'=P−n/2`、`B'=P+n/2`。因此P对应`t=0.5`，参数单位长度等于L的基准长度；**不能令P=t0，也不能把n归一化成1像素**。旋转方向按页面坐标计算，不额外翻y。〔静态证据；尚未原版拖动实验〕

路径基准已由路径点量测：39 个可见的「垂线上的点」(15) 的原版 EMF 点全部与 `X=A'+t(B'−A')` 一致（A'、B' 如上），说明 P 对应 t=0.5、参数单位为 L 的基准长度。〔已验证：路径基准；垂线本身的图元因线类对象在 EMF 里为被剪裁的长线，M2 匹配器暂未断言〕
