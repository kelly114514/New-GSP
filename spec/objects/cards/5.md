# 5 — 过点的垂线

头：主类 2 / genera 47（表内 genera42）。父：`[点 P,直线型对象 L]`，8,233 个对象全两父；父模板 `[4,7,0]`。L 可是线段、射线、直线、垂线、平行线、角平分射线及坐标轴；实际也有工具线占位。不能要求 L 的约束 ID 恰为 63。〔已验证：父形态；语义静态证据〕

L 有基准方向 `d=(dx,dy)` 时，结果是过 P 的无限直线，方向与 d 正交。L 的有限线段/射线范围不限制构造出的垂线。父不存在或 `|d|=0` 时结果不能确定。〔静态证据〕

**用于路径参数的方向正负尚未确定。**可用任一正交方向绘制同一条线，但给它构造路径点或求 11/12 分支时不能随意取向，否则下游位置会反向。基准第二点离 P 的尺度也待核对。无 kind 2003 或类专有 23xx。自由父拖动后重算；外观见 [通用契约](README.md)。
