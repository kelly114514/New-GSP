# 119 — 按标记角绕中心旋转

像的头：点（2 个对象，2 个文件，`(inRm)摆线.gsp`）。三父：`[源 B,中心 C,标记角 m]`，父模板 `[88,4,74,0]`；实际 `[(29,1),(29,1),(114,18)]`，m 是约束 114（标记优角 ∠b c d）的主类18对象。**无 kind 2003**。资源描述：「A 是 B 关于中心 C 旋转角度为 d 的旋转结果」。

标记角对象（113 劣角、114 优角、115 逆时针角、116 顺时针角，主类18 / genera74）把一个角固定成可作变换参数的「标记」。旋转角取标记角的值，方向约定同 [27.md](27.md)（逆时针为正；优角取大于 180° 的那个、116 为负方向）。〔静态证据：资源描述；2 个对象均未验证〕**没有可见匹配证据**，标记角的数值定义留给 M5/M4 的标记对象卡片（本批未写）。与 [29.md](29.md) 数学上等价，差别只在父的类型。
