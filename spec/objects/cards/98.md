# 98 — 含采样曲线的交点

头：主类1 / genera45。744 个对象全两父，kind 2002 长12，并全有8字节 kind 2003。父模板 `[87,84,0]`。实际第二父是轨迹/函数等采样路径，或工具输入占位；第一父含直线型、圆、弧，也有采样曲线。它不是 9/11–14 的别名。〔已验证〕

kind 2003 为 `u32 98; u32 selector`，后一字段观察到0、1等；其分支/索引语义待静态核对，不能当作 f64 坐标。无 kind 2201 或类专有 23xx。原记录须原样保留。〔已验证：结构；selector命名仅占位〕

几何含义是两个父路径的交点；采样、求根精化、选哪一个交点以及拖动时如何维持身份尚未确定。手册允许直线型/圆与轨迹、同自变量函数之间求交，不能从约束ID98推断任意两条路径都可求交。〔静态证据〕

本类型列在 A 组只是项目分组，不解除其对 M6 曲线规格的依赖。M2 必须区分 `unsupported-parent` 与 `nonexistent`，祖先含未实现曲线的对象不计为通过的 A 组几何。不得用两个父包围盒或折线首交点冒充原版。样式与标签见 [通用契约](README.md)。
