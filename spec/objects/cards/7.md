# 7 — 角平分射线

头：主类2 / genera44（catalog内部genera39）。2002父表：`[点 A,点 B,点 C]`，B是角顶点；202个对象全三父，kind2002长16。原版HTML唯一父图绑定5例、自由点相对位置匹配11例均同序；**不沿用2的反序**。父模板虽与线段同为 `[95,4,0]`，不能据模板值推父个数或统一重排。无kind2003或类专有23xx。〔已验证〕

对非零向量 `u=A−B`、`v=C−B`，内角平分方向与 `u/|u|+v/|v|` 同向。结果为从 B 出发的**射线**，不能画成无限直线。其两个臂的长度不应给角度加权。〔静态证据〕

任一父不存在、A=B 或 C=B 时不存在。两臂相反（平角）时的方向选择、两臂同向时的原版处理、路径点 t=1 使用的基准长度尚待核对。直接拖动平分射线反向影响哪些父未实测；M2 支持自由父拖动后重算。样式与标签见 [通用契约](README.md)。
