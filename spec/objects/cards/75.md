# 75 — 动态颜色

不是几何变换：像的**几何与源 `parents[0]` 完全相同**，颜色由其余父（数值）每次求值时驱动。头的主类/genera 随源而定：点 1,953、线段 999、多边形边界 4/52–55 约 451、圆 145、圆内部 67、弧 13、扇形/弓形 26 等。3,681 个对象（508 个文件）。〔已验证〕

## 父与 kind 2003（24 字节）

父：`[源 B, 数值父 …]`。两种形态：2 个父（`[源,x]`，一个数值）有谱系或灰阶；4 个父（`[源,x,y,z]`，三个数值）有 RGB 之类三通道。父的数值多为 (48,mk11) 或度量 (94,mk7)。

```
+0   u32  = 75
+4   u32  mode        上色方式码，见下
+8   f64  lo          数值范围下限 ┐ 与 HTML Colorized_*(…,lo,hi,…) 对应
+16  f64  hi          数值范围上限 ┘
```

mode 与 HTML 步骤名的对应（由 HTML 与 2003 配对统计）：18 → `Colorized_Spectrum`（2 父，约 987 个）；16、17 → `Colorized_Spectrum`（少数）；32、34 → `Colorized_Grayscale`（2 父）；50 → `Colorized_RGB`（4 父，约 1,278 个）；48 → `Colorized_RGB`（少数）；64、66、33 的对应关系〔未知〕。lo、hi 的语义（各通道范围还是一个范围）和 mode 的完整含义〔未知〕：这里只定结构，实现保留原载荷。

## 几何

`geometry(75 对象) = geometry(parents[0])`，不做任何变换；源不存在则不存在；其余数值父不存在或非有限时像是否不存在〔未知〕。对象头 +12..14 的 RGB 保存的是**最近一次求值的颜色**，不是固定颜色（可见匹配把对象头颜色与 EMF 图元颜色相比一致）。

证据：可见且唯一匹配 EMF 的对象 593 个（点 457、线段 58、内部 28、多边形 23、弧 13、圆 8、扇形 6），均是「几何与源相同且颜色等于对象头颜色」。33 个未对上，主要是一个渐变色文件和一个霓虹效果文件（颜色序列很多、图元合并或被覆盖），没有给出几何反例。颜色计算本身的验收需要 D 组数值，M4 只验收几何同源。
