# 26 — 按数值方向、数值距离平移

像的头：点（53 个对象，20 个文件）。三父：`[源 B,方向值 c,距离值 d]`，c、d 都是数值父，实际为 (48,mk11) 参数/计算值或 (37,mk7) 距离度量；父模板 `[88,44,43,0]`。**无 kind 2003**。资源描述：「A 是 B 沿 c 方向平移 d 的结果」。

定义：`p′ = p + D·(cos φ, −sin φ)`，φ 为方向值（角度，页面上逆时针为正，单位随数值父），D 为距离（像素）。依赖数值父（D 组），没有可见匹配证据。〔静态证据〕与 [118.md](118.md) 是同一运算的不同父形式。
