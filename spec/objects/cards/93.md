# 93 — 射线与多边形边界的第一个交点

头：主类1 / genera45。父：`[射线 R,多边形内部 P]`，269 个对象全两父，kind 2002 长12；父模板 `[13,15,0]`。实际射线为约束64或其变换像，第二父大多约束8；有工具输入占位。无 kind 2003 或类专有 23xx。〔已验证〕

令射线 `R(t)=A+t d,t≥0`。逐个和 P 的有序闭合边求交，从位于射线上的有限交点中选 t 最小者，即最靠近射线端点的边界交点。即便射线端点位于多边形外部，也返回第一次进入边界；端点在内部时是第一次离开边界。**不能选“最近顶点”，也不能把射线当无限直线。**〔静态证据：手册首交点定义〕

父不存在、射线退化或正向没有边界交点时不存在。顶点被相邻两边重复命中需合并同一几何点；射线和边重合、起点恰在边界时如何定首交点尚待原版实验，不得宣称已兼容。自交多边形按边界求交，不先按填充区域化简。M2 自由父拖动后重算；无历史分支参数。样式与标签见 [通用契约](README.md)。
