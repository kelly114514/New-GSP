# 32 — 按共线三点之比缩放

像的头随源而定：点 3,535、多边形边界 11、线段 18 等。3,573 个对象（205 个文件），五父：`[源 B,中心 C,D,E,F]`，D、E、F 是三点，父模板 `[88,95,4,0]`（数量码展开成五个父）；源与 C、D、E 多为自由点或其它 32 的像，F 多为路径点 (15)。**无 kind 2003**。资源描述：「A 是 B 关于中心 C 缩放比为 DF/DE 的缩放结果」；HTML `Dilation/3PtRatio(源,中心,D,E,F)`。

## 定义

`k = ± |DF| / |DE|`，其中符号为正当 F 与 E 在 D 的同侧，**负当 F 在 D 的另一侧**（`(F−D)·(E−D)<0`）；`p′ = C + k·(p − C)`。手册说明由同一直线上三点标记的比「根据方向的变化，比值可以是正、零、负」。〔已验证〕

证据：可见且唯一匹配 EMF 的对象 57 个（点 46、多边形 11），涉及 22 个文件；D、E、F 在这些对象里全部共线。负比有 1 个对象（`example-23`，F 在 D 另一侧）及其后继，若取无符号比则失配，改用带符号比后全部一致——**负比的证据只有一个对象**，另需更多样本。D、E、F 不共线时的比值定义（投影还是距离比）〔未知〕：语料可见状态里没有。DE=0 时像不存在。其余同 [16.md](16.md)。
