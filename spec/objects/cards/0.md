# 0 — 自由对象（M2：自由点）

## 识别与存储

约束 0 仅表示没有几何父约束，**不等于自由点**。30,287 个对象全无 kind 2002 / 2003。实际主类分别为 1（点，17,760）、0（文字，3,402）、10（1,983）、11（6,847）、16（图片，295）。M2 只求值主类 1；其余保留原记录并交给相应里程碑。〔已验证〕

主类 1 必有且只有一条 kind 2201，16 字节：`f64 x; f64 y`，无额外 23xx。其 genera 不限于 4：其中 16,585 个为 4，其它可能是工具输入占位，按通用契约处理；不要只凭 genera 把主类 1 改成另一主类。〔已验证〕

## 几何、存在性与拖动

无父，位置直接是 `(x,y)`。坐标有限时存在；非有限输入的原版容错〔未知〕，实现须报告无效几何。直接拖动到页面 `(x',y')` 改写两个坐标并重算所有后代。标签、颜色等不随坐标值重新生成。〔已验证：基准点与拖动后中点；非有限规则为实现容错〕

kind 2200 / 2210 / 2211 不能读成点，kind 2216 不能读成两个坐标。主类 0/10/11 有对应 23xx；主类 16 有 2316 与图片引用，详见格式规格。默认外观及标签见 [通用契约](README.md)。
