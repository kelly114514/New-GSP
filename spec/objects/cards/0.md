# 0 — 自由对象（M2：自由点）

## 识别与存储

约束 0 仅表示没有几何父约束，**不等于自由点**。30,287 个对象全无 kind 2002 / 2003。实际主类分别为 1（点，17,760）、0（文字，3,402）、10（1,983）、11（6,847）、16（图片，295）。M2 只求值主类 1；其余保留原记录并交给相应里程碑。〔已验证〕

主类 1 必有且只有一条 kind 2201，16 字节：`f64 x; f64 y`，无额外 23xx。其 genera 不限于 4：其中 16,585 个为 4，其它可能是工具输入占位，按通用契约处理；不要只凭 genera 把主类 1 改成另一主类。〔已验证〕

## 几何、存在性与拖动

无父，位置直接是 `(x,y)`。坐标有限时存在；非有限输入的原版容错〔未知〕，实现须报告无效几何。直接拖动到页面 `(x',y')` 改写两个坐标并重算所有后代。标签、颜色等不随坐标值重新生成。〔已验证：基准点与拖动后中点；非有限规则为实现容错〕

kind 2200 / 2210 / 2211 不能读成点，kind 2216 不能读成两个坐标。主类 0/10/11 有对应 23xx；主类 16 有 2316 与图片引用，详见格式规格。默认外观及标签见 [通用契约](README.md)。

## 数值自由对象（约束 0 / 主类 11）：参数与函数定义

自由对象里主类 11 的 6,847 个是**数值对象**，全部带 kind 2311（表达式），全部没有 2002。〔已验证：全语料结构〕

- **值是它自己的表达式**：2311 的 token 区按 [格式规格 §8.11](../../format/gsp-format.md) 解读；因为无 2002，token 区里不应出现 `0x6000+i` 父槽，出现即视为布局不符，报未支持。
- **genera 只作旁证**：79 无单位参数（表达式是纯数字）、80 长度参数（表达式带 `cm` 后缀）、81 角度参数（带度后缀）、51/48/49 无单位/长度/角度计算值。33（1,786 个，标签形如 `t[1]`、`n`，表达式多为单个 `0`）语义〔未知〕，其值仍按其表达式求，不要靠 genera 猜；60/18/1 是工具区占位。
- **genera 57 是函数定义，不是数值**：284 个，`+46` 取 0..3，其中 205 个 token 区含 `0x000F`（函数自变量占位）。本批不求值函数，遇到即报未支持，**不得把 `0x000F` 当数字 15**。
- 显示：文字位置 `+12/+14`、小数位数 `+28` 与度量相同；`2211` 是位置框，`2005` 是参数名。数值对象不产生几何，只有 `kind="measure"` 输出。
- 拖动/编辑参数值会改变所有引用它的计算与变换（本批只读，不实现编辑）。
