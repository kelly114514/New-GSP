# 34 — 关于镜面的反射

像的头随源而定：多边形边界 4/52 1,517、线段 2,060、点 2,439、直线 561、圆 81、弧 67、内部 23、扇形/弓形 11 等。6,899 个对象（378 个文件），两父：`[源 B,镜面 L]`，父模板 `[88,7,0]`；L 是直线型对象，实际全为 mk2：线段 (2)、垂线 (5)、反射或旋转的线段像 (27、34)、直线等。**无 kind 2003**。资源描述：「A 是 B 关于镜面 C 的反射结果」；HTML `Reflection(源,镜面)`。〔已验证〕

## 定义

镜面是 L 的支撑直线（线段、射线的有限范围不限制镜面）。设 L 的基准点为 A′、B′（线段/射线/直线为其 2002 两个父，垂线/平行线见 [5.md](5.md)、[6.md](6.md)），单位方向 `(dx,dy)=(B′−A′)/|B′−A′|`：

```
M = [[2dx²−1, 2dxdy],[2dxdy, 2dy²−1]],   p′ = A′ + M·(p − A′)
```

反射使**弧像的扫角取反**，圆像半径不变，多边形顶点序不变（但朝向反转，渲染不应因此翻转填充）。〔已验证〕

证据：可见且唯一匹配 EMF 的对象 959 个（多边形 853、点 50、线段 45、弧 5、扇形 4、圆 2、直线 2），涉及 51 个文件；弧像和扇形像 9 个全部一致（若不取反扫角则弧、扇形失配）。10 个多边形在 EMF 里没有对应的填充多边形图元（`计算概率`）。L 退化（基准点重合）时像不存在。其余同 [16.md](16.md)。
