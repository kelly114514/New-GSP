# 24 — 按数值父给出的距离、固定角度平移

像的头随源而定：点 4,081、线段 286、其它。4,385 个对象（327 个文件），两父：`[源 B,距离值 c]`，c 是数值父，实际是计算值 (48,mk11) 3,019 个、自由参数 (0,mk11) 677 个、长度度量 (36,mk7) 451 个、距离度量 (37,mk7) 216 个及其它少数；父模板 `[88,95,43,0]`。资源描述：「A 是 B 通过移动距离为 ^c 移动角度为 ^4 的平移结果」。

## kind 2003（36 字节）

```
+0   u32  = 24
+4   f64  a            = −sin θ
+12  f64  b            =  cos θ
+20  f64  angle        角度数值，单位见 +28
+28  u32  angle_unit   0=弧度 1=度 2=度
+32  4 字节            残留
```

固定的是**角度**，布局与 [21.md](21.md) 的前 32 字节相同。4,385 个载荷中 `a²+b²=1` 且 `atan2(−a,b)` 与 `angle` 在各单位码下一致（0：166、1：4,203、2：16）。〔已验证：布局；语义静态证据〕

## 定义

`p′ = p + D·(cos θ, −sin θ)`，θ = `atan2(−a,b)`，D 是数值父 c 的当前值换算成页面像素（长度单位乘以单位换算因子，1 cm=37.7953 px）。依赖数值/度量（D 组），**没有可见匹配证据**，〔静态证据〕，M5 验收。角度方向、位移符号约定与 [21.md](21.md) 相同。父不存在或值非有限时像不存在。
