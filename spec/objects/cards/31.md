# 31 — 按两线段长度之比缩放

像的头：点 7、线段 1（8 个对象，5 个文件）。四父：`[源 B,中心 C,线段 d,线段 e]`，父模板 `[88,4,14,14,0]`。**无 kind 2003**。资源描述：「A 是 B 关于中心 C 缩放比为 d/e 的缩放结果」；HTML `Dilation/SegmentRatio(源,中心,d,e)`。

定义：`k = |d| / |e|`，`p′ = C + k·(p − C)`（手册：第一条线段长为分子，选定顺序决定分子分母）。e 长度为 0 时像不存在。8 个对象在语料中都是隐藏的或未被导出，**没有可见匹配证据**，〔静态证据〕。比的符号（线段是否有向）〔未知〕。
