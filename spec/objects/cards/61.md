# 61 — 两轴定义的直角坐标系

〔结构〕主类8/genera39；有序父 [水平轴 X,竖直轴 Y]，通常58/59/60。2308旧布局2字节、新布局8字节；首u16模式1或2是本批子集，其余字保留。

〔已验证：原版 EMF/HTML 数值〕两轴同原点O，u=X.b−X.a=(Lx,0)、v=Y.b−Y.a=(0,−Ly)，Lx,Ly>0，可不相等。页面P=O+x*u+y*v；反向解二元方程取坐标。坐标无量纲，不随10041/10042变化。HTML CoordSysByAxes父序与此一致。

输出语义对象kind:coordinate-system,origin,u,v，status=ok、exists=true；无自身可见图元，不伪造直接EMF断言。渲染器安全忽略容器，两轴独立绘制。

〔未知〕模式非1/2、未知布局、错序、不同原点、同向轴、斜轴、奇异基及非正单位必须报未支持。网格样式、极坐标模式与拖动未验收。

父不存在传播 not-existing；父未实现传播 unsupported / parent:N:unsupported。未核证边界必须报 unsupported 并说明原因；原记录无损保留。数值显示沿用 [数值契约](../../acceptance/m5-measures.md)，证据命令和样本数见 [本批报告 §2–3](../../acceptance/m5-batch2.md)。
