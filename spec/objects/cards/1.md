# 1 — 中点

头：主类 1 / genera 11。父：`[线段 S]`，不是 `[端点 A,端点 B]`；3,887 个对象的 kind 2002 都为 8 字节。父模板 `[14,0]`；实际父多数是约束 2，也有变换后的线段和工具输入占位。主类 1/genera14 的自由父不能未经工具绑定当线段。〔已验证〕

设 S 的有序端点为 A、B，则 `P=(A+B)/2`。父不存在则 P 不存在；两个端点重合时原版如何处理退化线段待核对，不能因当前图上看不见线段就判父不存在。〔静态证据；退化边界未知〕

无 kind 2003、2201 或类专有 23xx；坐标只由父推出。样式和标签见 [通用契约](README.md)。不单独存“中点位置”；自由父拖动时重新求值。基准 `midpoint.gsp` / `midpoint-moved.gsp` 的 P 分别为 `(311,214)` / `(331,227.5)`。〔已验证〕
