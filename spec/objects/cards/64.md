# 64 — 从一点通过另一点的射线

头：主类2 / genera13。2002父表 `[A,B]`，3,934个对象全两父。无kind2003或类专有23xx。原生第一父A是射线端点，第二父B定方向与参数尺度。〔已验证：原版EMF路径点；结构全语料〕

`X(t)=A+t(B−A),t≥0`，包括A；B不是另一端。原版EMF独立量测13个非对称路径点全匹配同序、反序零匹配；例如父(30,545)、(192,545)，t=1.6812613501140852，EMF点(302.364,545)。〔已验证〕显示时只向B方向延伸并裁剪视口，不能为画箭头而修改计算方向。任一父不存在或A=B时不存在；精确零方向由原生静态求值确认，近退化阈值待核对。

HTML的Ray实参有反序约定（唯一父图绑定92例、自由点匹配76例），**不能据此反转原生.gsp射线方向**。

原版 Sample 射线点的 2003 为 `u16 15,u16 13,f64 0.6598214285714283`，HTML 导出为同一父路径上的点值 0.659821，见 [15.md](15.md)。自由父拖动后重算。样式与标签见 [通用契约](README.md)。
