# 64 — 从一点通过另一点的射线

头：主类 2 / genera13。父：`[点 A,点 B]`，3,934 个对象全两父。无 kind 2003 或类专有 23xx。A 是端点，B 定方向和参数单位。〔已验证：结构；语义静态证据〕

`X(t)=A+t(B−A), t≥0`，包括端点 A；B 不是另一端。显示时只向 B 方向延伸并裁剪视口。任一父不存在或 A=B 时无可确定射线；退化阈值待核对。不能为画箭头而修改计算方向。〔静态证据〕
