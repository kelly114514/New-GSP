# M3 第一批：自由点编辑、历史与另存为

本批产品契约（2026-10-24）。在现有查看器上完成“打开 → 拖动自由点 → 撤销/重做 → 另存为 → 重开”。这是本项目选定的交互规则，未动态核证的历史粒度不宣称与原版完全一致。对象几何和存档仍以已有格式/对象卡片为准。

## 编辑事务与历史

- 一个文档共享跨页历史。自由点仍通过已有自由点修改与依赖重算接口修改；派生对象不新增拖动入口。
- pointerdown记录原坐标；pointermove即时预览；pointerup提交一条实际坐标发生变化的历史项。移动回起点不新增历史。pointercancel或Escape恢复起点，不新增历史。
- 历史项包含页次、对象序号、修改前后坐标；切页不清空历史。撤销/重做定位到该操作所在页并更新几何。撤销后提交新编辑清空重做分支。
- Ctrl+Z撤销，Ctrl+R重做；菜单显示对应动作，无可用动作时禁用。输入控件聚焦时不截获其原生编辑快捷键。进行中的拖动先取消，再处理历史操作。
- 成功打开另一个文档后创建新历史；打开取消或解析/读取失败保持原文档、历史与修改状态。若当前文档有未保存修改，替换前由用户明确选择放弃或取消。

## 修改状态与文件写出

- 文档保留原打开路径和最近成功保存路径；标题及状态栏显示未保存修改。修改状态依据当前写出字节与最近成功打开/保存的字节检查点是否一致，不得仅按历史深度判断。
- 文件菜单增加“另存为…”（Ctrl+Shift+S）。原生保存对话框只选择.gsp；取消返回原状态。使用现有writeGsp，不生成新的自有格式，不丢未知记录。
- 保存操作保存确定的文档快照；取消、写失败不更新路径/文件名/保存检查点。成功后更新最近保存路径、文件名和保存检查点；保存期间如发生后续编辑，后续编辑仍标为未保存。阻止重复保存及异步打开/保存之间互相覆盖状态。
- 无文档时禁用另存为和历史操作。拖动进行中先提交当前实际变动再保存。写出失败显示中文可恢复错误，画布与历史继续可用。
- 只增加保存对话框和写选定文件所需的Tauri权限；不要开放全盘读写。浏览器预览对不支持的文件操作给出可恢复错误。

## 本批边界与验收

- 不包含新对象构造、删除、文本、属性、多选或新增页面。它们待对应写出规格补齐后另批交付。
- 历史测试覆盖一次多次move只记一步、无变化、取消/Escape、撤销重做、新分支、跨页、恢复到检查点、同历史深度不同分支仍为脏。
- 保存测试覆盖对话框取消、写失败、成功保存、重复操作及异步快照；重新解析保存字节验证对象图和几何，未修改文档逐字节一致，撤销全部后恢复原字节。
- 用baseline的midpoint.gsp拖动对象1由(211,147)到(251,174)，中点更新；另存为后重开仍保留目标自由点和派生中点。未知记录及未编辑页仍保留。
