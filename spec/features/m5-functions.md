# M5 第三批：单变量函数定义与计算调用

本批只实现**约束 0 / 主类 11 / 存档 genera 57 / 2311 模式 0** 的函数定义，以及约束 48 对它的调用。函数是带自变量的表达式容器，不是度量值，也不是函数图像。约束 62 是动作按钮，另见[62 卡片](../objects/cards/62.md)，不在本批产品实现范围。

## 1. 身份与存储

所有编号均为存档外部 ID，不能把目录中的 genera 表内索引直接当作存档 ID。自由函数的识别条件是 `(constraint,mainKind,genera)=(0,11,57)`，不能只看名字 `f` 或主类 11。

全语料有 284 个自由函数，分布在 110 文件；全部无 2002，无 2003，全部有一条 2311。模式字分布：0 有 276 个，1 有 4 个，2 有 3 个，3 有 1 个；205 个函数体含自变量 token。常数函数没有自变量，仍是函数，不能因此退回普通数值对象。

2311 的下列偏移均从载荷起算，布局 4/5 相同：

| 偏移 | 类型 | 规则 |
|---:|---|---|
| 0..31 | bytes | 共同文字前缀，保留；保存位置在 +12/+14 两个 i16 |
| 32 | u32 | 必须为 2311 |
| 36 | u32 | 必须为载荷总长减 32 |
| 40 | u32 | 观测为 48；不是此对象的约束 ID |
| 44 | u16 | token 数 N |
| 46 | u16 | 表达式形式；本批只支持 0，不能要求是计算值使用的 4 |
| 48..91 | bytes | 不透明，原样保留，不能读作函数值或默认实参 |
| 92.. | N 个 u16 | 小端中缀表达式；载荷总长严格为 `92+2N` |

模式 0 的正文用以下 token，运算规则继续遵守[48 卡片](../objects/cards/48.md)：

| token | 含义 |
|---|---|
| 0..9、10 | 数字字符与小数点；连续字符组成数 |
| 11、12 | 左、右括号 |
| 13、14 | π、e |
| **15（0x000F）** | 本次调用的唯一自变量 `x`；绝不是数字 15，也不是父槽 |
| 0x1000..0x1004 | 加、减、乘、除、幂；操作数位置的减号为负号 |
| 0x2000..0x200C | sin、cos、tan、asin、acos、atan、abs、sqrt、ln、log、sgn、round、trunc；token 自带左括号，以 12 结束 |

自由函数无父表，函数体中的 `0x6000+i`、`0x7000+i` 没有合法绑定，必须未支持，不能跨到调用者的父表。函数体显式单位后缀在存档中有少量样本，但本批没有对应直接原版数值断言，先报 `function-body-unit-unverified`。其它未列 token 同样未支持。数值自由对象的模式 4 继续按原契约处理；其中遇到 15 不能当成一个自由函数。

## 2. 函数的语义接口

页面求值应保留一个可调用的函数对象，至少携带对象身份、mode、token/表达式树及其页面数值环境。具体 TypeScript 类型可由实现方设计，但必须能表达以下区别：

- 函数定义求值成功表示“可调用”，不附 `measurement`，不附虚构的默认数值，不在没有实参时执行正文。
- 调用在独立的局部环境中绑定 `x`。连续调用 `f(a)`、`f(b)`，以及 `f(g(a))` 的内外环境不能共享可变的 `x` 缓存。函数原记录也不能因调用被修改。
- 参数或几何改变后，依赖此调用的 48 及其后代正常重算。函数名仅供显示，解析不按名称寻找同名对象。
- 函数 `1/x` 在未调用时不因假定 `x=0` 变成不存在；实际调用遇到无穷、未定义时沿用现有数值分类。函数容器不存在/未支持、实参祖先阻塞、数学非有限值必须分开。

本批不新增函数正文的画布排版，不把函数定义渲染成普通读数；不实现新建/编辑函数或原版兼容的新建写出。打开再保存仍须保留全部原字节。

## 3. 48 的函数调用

调用 token 是 **`0x7000+i`**，`i` 为当前 **48 对象完整、有序 2002 父表**的 0 起槽号。父表同时容纳函数和数值父，不能先过滤出函数再编号，也不能把 i 当页内对象序号。

语法为 `call-token argument-expression 12`；call-token 自带左括号。一个完整中缀表达式是一个实参，括号、嵌套内置函数和其它已支持的调用均按正常括号深度解析。没有逗号、多实参或隐式第二实参。

例如父表 `[211,215]`、tokens `[0x7000,0x6001,12]` 表示“调用页内对象 211，以页内对象 215 的数值为实参”。父表 `[F,A,B]`、`[0x7000,0x6001,0x1002,0x6002,12]` 是 `F(A*B)`，不是 `F(A)*B`。`0x6000+i` 的意义不变：只能读取数值，不能把一个函数容器隐式转换为数值。

调用步骤：先解析并求实参；按原有度量契约取得实参的**未舍入页面显示单位值**；确认被调用父是本批支持的函数；在同一页面数值环境下把值绑定给 `x` 并求正文；再回到调用者的表达式继续计算。调用不先将角度强行换成弧度，也不先将长度换成 px。内置 sin/cos/tan 仍用页面 10042 指定的角度单位；反三角函数仍输出页面角度单位。

本批已核对的实参/结果量纲子集是：

1. 无量纲实参：把 `x` 作为 number，按既有表达式规则推函数体结果量纲；例如 `asin(x)` 输出 angle，`sin(2*x)` 输出 number。
2. 角度实参：**正文严格为 `sin(x)`** 时支持，以该角度的未舍入页面读数传入，再按页面角度模式解释。`example-59` 两条直接读数覆盖此分支。
3. 其它角度正文、长度/面积实参、函数体单位后缀及跨量纲边界：先报 `function-argument-dimension-unverified` 或 `function-body-unit-unverified`。不能用上面两条推断任意带单位函数的替换规则。

调用结果沿用 48 的量纲核对：推得结果与调用对象 genera 48/49/50/51 不一致仍报 `dimension-mismatch-unverified`，不因“它是函数”绕过该保护。实参是 angle 而函数为 `sin(x)` 时结果是 number，不继承实参的 angle。

## 4. 未支持边界与失败

| 条件 | 本批结果 |
|---|---|
| 函数模式 1/2/3 | `function-mode-unverified`；仍保留模式与原记录 |
| 调用父为约束 71、70 或其它函数族 | `function-callee-unverified`，不能借用自由函数规则 |
| 调用槽越界、缺右括号或无实参 | 显式无效表达式/未支持，不能返回 0 |
| 父槽指到点、直线、62 按钮或其它非函数 | `function-parent-not-callable` |
| 非本批实参量纲/函数体单位 | 按 §3 显式未支持 |
| 数值父祖先尚未实现 | 沿用祖先阻塞；不能吞掉已获得的错误结果 |

最后两行的检查顺序不同：父槽本身是点、直线等几何对象时，在进入函数规则之前就按父类型报 `parent:N:numeric-value-required`；父槽是数值度量、却被 `0x7000+i` 当函数调用时，才报 `function-parent-not-callable`。两者都是自身未支持，汇总时按类别分别计数，不合并成同一种失败。

模式 1/2/3 的存档标签分别出现 `x=f(y)`、极坐标形式等旁证；本批不借这些名字推导运行语义。约束 71 的函数体可以引用其它参数/函数，与无父的自由函数不同；它贡献的大部分已有函数调用读数仍不属于本批实现范围。函数图像、导函数、参数曲线、声音和按钮均另列后续工作。

## 5. 证据强度

- **结构证据**：1,431 文件，284 自由函数；mode 0 有 276 个；843 个 48 含调用 token，其中 228 个只直接调用自由 mode-0 函数。结构数量不等于这些对象都已取得原版值或都可求值。
- **原版直接数值断言：14 条**，全部为 48 调用的原版 EMF 显示读数，来自 7 页；自由函数容器本身没有普通数值读数，直接值断言数为 0。另 1 条 mode-1 自由函数调用、80 条其它/混合函数族调用均未计入这 14 条。
- **正文/调用结构旁证**：原版 HTML 将 `0x000F` 导出为 RPN `x`，将 `0x7000+i` 导出为 `@fA/@fB/...`；HTML 的弧度常数和数值精度不覆盖原生单位规则。`Sample.gsp` 页 1 的自由函数 211 是 `0.5*x+1`，原版 HTML 的对应 Function 正文为 `0.5 x * 1 +`；不能直接把 HTML step 110 当作原生对象号 211。
- **本轮未启动原版**，没有新的动态操作实验；14 条是已有真实读数的原样子集，不是 14 条新增原版观测。详见[验收](../acceptance/m5-batch3-functions.md)。
