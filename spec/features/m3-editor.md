# M3 编辑器：行为规格（工作版）

范围：工具箱基本构造、选择/拖动/删除、构造菜单、撤销重做、自动标签及新建对象写出。本文只规定资料能支持的行为；手册和资源串是静态证据，不等于已运行原版验证。遇到菜单实际灰显条件、快捷键或二进制字段没有足够证据时明确保留待实验。

## 证据标记与来源

- **〔手册〕**：`reference/features/manuals-text/几何画板使用手册.txt` 的功能说明；页码均为 PDF 物理页。
- **〔静态〕**：由资源菜单声明、工具提示/对象描述串或对象目录统计得出，未验证运行时。
- **〔格式〕**：`spec/format/gsp-format.md` 中已整理的 GSP 结构/写出结论。
- **〔推断〕**：为实现形成的最小行为假设，必须由验收覆盖，不能称作原版行为。
- **〔待实验〕**：需要原版交互或差分存档才能定稿。

主要来源：手册 PDF 17–32（物理页 18–33，工具箱），PDF 22–26（选择/拖动/标签），PDF 39–47（构造菜单）；对应提取文本位置见 `reference/features/manuals-text/几何画板使用手册.txt`：工具箱 L754–840，构造菜单 L1758–2065，选择/删除/拖动 L1027–1151，标签 L1181–1191，撤销 L1325–1342。`reference/features/menu-commands.md` 是资源静态表中的主程序顶层菜单（文件/编辑/视图/测试/窗口/帮助等），**不含构造菜单子项**；构造菜单项以手册第三章第一至第五节为清单来源，不把静态顶层菜单命令误作构造命令。对象约束/样本分布见 `spec/objects/catalog.json` 与 `spec/objects/cards/`；写出见 `spec/format/gsp-format.md` §7.5、§8、§10.2。手册具体操作已用本规格自己的话概括。

## 选择、拖动、删除

### 选择

- 常规对象选择在移动箭头工具下执行。单击对象加入当前选择；继续单击其它对象会保留原选择，无需 Shift；再次点击已选对象将其从集合中移除。空白处单击或 Esc 清空选择。〔手册 PDF 22〕
- 普通拖框可选多个对象；按住 Shift 框选可在彼此分开的区域追加选择，且在 Shift 连选时点击空白不清掉已有选择。重叠点/线须按住 Shift 多次点击逐个选中。手册还说 Shift 可用于连续选择，但普通逐个单击本身也会保留前项；不要把 Shift 描述成多选必需键。〔手册 PDF 23；文本 L1038–1083〕
- 点击命中区按对象形态区分：点选点心；线段避开端点；圆选圆周而不是圆心/周点。多个重合对象的循环命中、遮挡顺序待实验。〔手册 PDF 22–23〕
- Ctrl+A 的含义随当前工具改变：移动箭头选全部对象；点工具选全部点；线工具选对应线对象；圆、多边形、文本工具分别选对应对象类别。具体工具映射及“线”是否含三种线型待实验。〔手册 PDF 23〕
- 编辑菜单有“选择父对象”命令；已选对象的父对象成为选择集。对应“选择子对象”的精确行为、递归层数及快捷键未知。〔手册 PDF 23〕
- 已新建的最后一个对象默认保持选中。〔手册 PDF 23〕

### 拖动

- 拖动自由点更新其位置，并重新求值全部依赖后代；依赖关系保持不变。拖动构造对象本身可能移动其父对象以维持定义，但哪些对象可直接抓取、父对象反向移动的优先级未由本轮资料完全规定。〔手册 PDF 24–25；对象卡通用契约〕
- 拖动路径点应保持路径约束；移动到新路径位置后，约束参数更新，再传播给子对象。具体投影/边界行为按对象卡片，不能把约束点转换成自由点。〔静态：卡片 15〕
- 选中多个对象后拖动，手册说所选对象随之移动；同时存在依赖时怎样避免重复移动同一祖先，待实验。开始拖动前 Esc 清空或重新进入箭头状态，可避免仍在创建线/点模式下误操作。〔手册 PDF 24〕

### 删除

- 选中一项或多项后按 Delete/Backspace，或执行“编辑 → 清除对象”。〔手册 PDF 23〕
- 删除对象同时删除所有依赖子对象（递归级联）；因此删除辅助对象可能移除图上看似独立的构造结果。删除多个互有依赖的选中对象应只移除一次且不留悬空父引用。前两句有手册证据，后一句是实现约束。〔手册 PDF 23〕
- 是否出现级联确认提示、如何处理被其它页/工具引用对象、删除是否可只删派生约束并保留几何（分离/重接操作），待实验；M3 普通 Delete 必须按级联删除处理。

## 撤销与重做

- 单步撤销 Ctrl+Z；恢复/重做 Ctrl+R。按住 Shift 再选“撤消”可执行撤消所有，Ctrl+Shift+Z；恢复所有为 Ctrl+Shift+R。〔手册 PDF 28〕
- 撤销栈应覆盖结构和属性编辑，恢复后对象图、选择依赖与写出内容回到相应历史状态。手册称其可返回“刚打开画板的状态”，但单次撤销操作边界（一次拖动算一步、连续文本输入合并、属性对话框提交、撤销后的分支清空）未给出；列为待实验。
- 手册使用“恢复”称 redo；资源菜单静态表未列出撤销/恢复项，故菜单文字/动态灰显状态以待实验为准。无可撤销步骤时撤销灰显，无可恢复步骤时恢复灰显是〔推断〕。
- 新建、关闭文档与跨页面动作的撤销栈范围，工具操作取消是否入栈，均待实验。撤销/恢复所有不得误认为普通单步键行为。

## 自动标签与页计数器

- 手册描述：创建时自动给对象分配标签；点通常从 A 起用大写字母，线从 j 起用小写字母，圆使用 c1 起的编号；无通常标签的系统对象可显示 `#?` 一类序号名。具体标签显示与标签字符串分开，使用文本工具可隐藏/显示、移动、编辑标签。〔手册 PDF 25〕
- 页面 kind 2400–2419 对应外部主类 0–19 的计数器；2399 是额外末项。布局 5 有 20 个主类计数器，布局 4 到 2417 为止。记录格式/分派关系为〔格式 §7.5，静态证据〕。
- **计数器解释仍是推测：** 规格当前判断这些值承载自动命名的“下一个序号/命名进度”；其字节位含义依赖主类，2401、2402、2411 常见非零值位于 a，其余多在 b，样本偶有两者非零。不能简单把字段解作从 0/1 起的统一整数，也不能凭计数器直接推得最终可见标签。〔格式 §7.5〕
- 新文档/新页缺省计数器字节、创建并删除后是否回收名字、手动改名后是否占用名字、字母越过 Z 的规则、约束类到计数器主类的映射以及 2399 的实际用途，均待原版差分/构造实验。直到确认前，显示规则按用户可观察标签语义实现，存档计数器未知字节保留，不擅自改写。
