# 规格

规格方的产出，也是实现方唯一的输入。写规格的人可以读 `reference/`、使用 `re/` 和原版；写进这里的内容不带原程序地址、函数名和恢复过程，只描述文件结构、字段含义和行为。

| 路径 | 内容 |
|---|---|
| `format/` | .gsp 格式规格与记录 kind 表 |
| `objects/` | 对象目录 `catalog.json`（由 `tools/build_object_catalog.py` 生成）与对象卡片 |
| `features/` | 功能规格，按里程碑分批 |
| `acceptance/` | 验收用例：输入 + 操作 + 期望结果 |
| `questions.md` | 实现方提出的规格空白，规格方回答后移到对应规格里 |

每条结论标明来源等级：**已验证**（原版实验或全语料检验）、**静态证据**（来自原程序数据或代码，未经原版实验）、**推测**。
