# M5 第三批函数验收

功能与失败边界以[函数规格](../features/m5-functions.md)为准。本批交付 **mode 0 的无父单变量定义 + 48 对它的调用**；62 仅完成[身份/存储卡片](../objects/cards/62.md)，不要求产品执行按钮。

## 1. 原版值与统计口径

本机 `oracle/m5-batch3-functions/index.json` 是 r5 的只读子集：7 个 case/7 个活动页，14 条 `original_emf_text` 原版十进制读数。每条 assertion 对象与 r5 中对应对象逐字段相同，保留 source、source sha256、pageIndex、pageCount、oracle、原版文字、精度、容差和图元出处。源 case/index 的 SHA-256 也保存在子集 provenance 中。

这些是**14 条已有原版观测的专用索引**，不是本轮新增 14 次原版实验，不可与 r5 断言重复相加。函数容器的直接数值断言 0；按钮执行断言 0；函数曲线/导函数/模式 1–3 的本批直接断言 0。本轮不启动 GSP5chs.exe。

## 2. 必须通过的功能检查

1. 识别 `(0,11,57)` 的 mode-0 定义；常数函数仍返回函数容器。函数不输出数值读数，不在打开时以 x=0 执行。
2. `0x000F` 绑定实参；在普通 mode-4 数值对象内不能被读成数字 15。
3. `0x7000+i` 使用未过滤的有序父表；同一父表中的 `0x6000+i` 仍是数值槽。以非交换结构核对 `F(A*B)`、`4/x`，不以“数值刚好相同”代替结构正确。
4. 调用继承页面角度单位，且实参使用未舍入显示单位值。`example-59` 两条覆盖 angle→sin→number；`卧龙沟` 70 覆盖 number→asin→angle。禁止在 HTML RPN 与原生表达式之间偷偷统一成弧度。
5. 同一函数被不同实参调用时局部环境隔离；修改一个参数后相应 48/后代重算。可以用实现自造的简单数学测试检验环境隔离，但须标为**实现测试，非原版断言**。
6. 模式1/2/3、71等其它函数族、未知单位/量纲边界、非函数父、越界槽及未知 token 显式分类。函数正文与结果量纲不符时保留现有 mismatch 保护。
7. 全部现有 r5 数值/几何断言不得退步，未知分支不能以猜测有限数值增加覆盖。

14 条读数即使有尚未实现的祖先也必须保留，由比较报告分别记通过、算错、自身未支持、祖先阻塞；不能因为本批只实现函数而提前宣称 14 条全部通过。原版导出状态/动画/对话框继续以原 manifest 检查；复制索引不改变它们。

## 3. 离线生成与校验

从仓库根目录运行：

```powershell
python tools/m5_functions_evidence.py --out oracle/m5-batch3-functions
python -m unittest discover -s tools -p test_m5_functions.py -v
```

生成器只读 .gsp 和 r5：统计函数/62 的原生记录；筛出所有被调用父均为自由 mode-0 函数的原版 48 断言；完整拷贝原断言。它没有表达式数值求值器，不 import/call `impl`，不改已有工具和 r5。新增输出在单独目录，`oracle/` 不入库。

本批复跑结果：1,431 文件库存扫描通过；284 个自由函数中 mode0/1/2/3 为 276/4/3/1；843 个 48 含调用，其中 228 个只调用自由 mode0；62 为 14,312 个/993 文件，实际头 `(62,10,23)`；专用子集 **14 条/7 cases**；工具 **8 项测试通过**。这些命令只验证证据工具与原样索引，尚不是产品实现通过结果。

工具测试覆盖独立变量与数字15区分、非交换结构、常数函数、自由函数非法父槽、表达式长度截断、调用父槽边界、mode/身份筛选，以及14条真实期望逐字段保真。没有本机 oracle 时最后一项明确跳过，不能拿 CI 的其它 7 项通过代替本机证据保真。
