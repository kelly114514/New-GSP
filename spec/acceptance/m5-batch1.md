## 2. 验收结果

正式集合改为 **`oracle/m5-cases-r3`**，`oracle/m5-cases-r2` 停用。r3 用同一份原版导出离线重新生成，没有启动原版，和 r2 相比有三处变化：

1. **放开参数变换**：24、25、29、31、33 由规格方独立预测器 `tools/m5_numeric_hints.py` 给出搜索提示。提示只用来挑选唯一的 EMF 图元，期望值仍然从图元读回。实现算错时，预测不会跟着它一起错，所以错误不会被“找不到图元”掩盖。

3. r2 已有的期望值一条也没有改。

## 4. 显示格式化：三条证据

1. **舍入**：用 double 的精确值按 half away from zero 舍入。下面 3 条落在半值边界 ±1e-9 内的断言逐字一致：`0.6349999999999993 → 0.63`、`5.715000000000001 → 5.72`（两条）。它们的精确值都不是真正的半值，所以只是普通舍入的样本，**不能证明**真正半值时的规则。
2. **负零**：舍入结果为 0 时原版不输出负号。证据 `IFS-摇曳的蕨叶.gsp` 对象 67：内部值 −0.004001、`digits=2`，原版显示 `0.00`。
3. **单位字形**：`10042=0` 显示 `弧度`；1 与 2 都是度数，字形由对象字体决定（`Symbol` 用 `U+F0B0`，其余用 `°`）。`10041=1` 显示 `厘米`；`10041=0/2` 语料无样本，低置信。

## 6. r2 的两条“算错”：原版导出时在播放动画

`分形艺术/Arboresent.gsp` 对象 16（41）和 20（48）期望 21.83°，实现给 17.50°。首次交付把原因归为“点参数与 EMF 不一致、无法判定”，复审结论不同：

- oracle 清单记录这个文件打开后 `busy_after_open`、`animation_stop_sent`，关闭时原版提示“要保存更改吗”。所以导出时文档已经被动画改过。
- 三份状态互不一致：存档里 15 号点的参数是 0.68476；HTML 导出是 0.518756（另一时刻）；EMF 里红点 A 画在 (691.5, 350.39)。用 EMF 的位置算 ∠ARL 正好是 21.83°，说明实现的度量规则没有问题，是期望值取自动画中的一帧。
- 首次交付说“约束 15 没有一条几何断言”，不对：r2 里有 1,525 条，全部通过。

处理方式见 §2 第 2 条。不需要原版实验。


## 7. 仍未支持的边界（都是显式未支持，不是算错）

- 48：表达式量纲与 genera 不一致（`dimension-mismatch-unverified`，r3 语料 119 个，无断言）、`0x7000+i` 函数调用、`0x0102`/`0x0200`/`0x0202` 三个未核证单位 token、`0x1005`（只在无断言的工具文件里出现）、`genera=57` 的函数定义对象、36 字节 `2307` 变体（4 个对象，无断言）。
- 47：三点不共线（卡片明确未验证）；44 的三父形式；39/46 的非卡片父类型。
- 变换：数值父量纲不符卡片（`numeric-parameter-dimension-unverified`，21 个，无断言）、零比例（Q7）、32 非共线、22/117–119 未核证类型；A=B 同方向的 79/80、81 的精确分界与弦外点、零扫角后代。
- 75：只复制几何，不写颜色（卡片无公式）。
- 数值对象：页面偏好 `10041`/`10042` 缺失、需要 DPI 却缺 `9008` → 明确未支持，不假设默认值。

## 8. 证据等级

- **结构（强）**：49,419 个约束 48 的 2311 全部符合 token 区布局；6,847 个约束 0/主类 11 全部带 2311 且全部无 2002；本批扫描的 32 字节 2307 与全部 2311 的 `+28` 都在 0..5。
- **原版读数（强，逐字）**：442 条读数断言的单位文字与 `displayNumber` 逐字一致；3 条半值边界单列。
- **参数变换（中）**：24/29/33 有 16 条原版几何断言；25/31/18–20/23/26 没有，只有静态证据。
- **独立核对（强）**：106 条定义级核对 0 失配。
- **求值模型（中强）**：把「数值在页面显示单位里、三角函数按页面角度单位换算」这条模型独立复算，与原版读数 420/422 一致，另 13 条差异全部由字体字形解释。
- **合成输入（中）**：79/80 的 `|OA|` 半径来自 2026-10-24 原版 EMF 合成导出，不是 UI 构造实验。
- **未验证（低）**：`10041=0/2` 的字形、缺失 `+28` 的回退值、负距离、75 的配色、面积单位上标。无量纲数值父当角度/长度、genera 与表达式量纲不一致，这两种已改为显式未支持。
