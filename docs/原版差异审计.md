**以下做法是第一批的推断，仍没有回原版核对**（第二批用原版核对了动画命令状态、自定义变换的创建条件、参数曲线、打印预览比例，其余没动；第二批自己的推断——声音播放参数、文本样式大小比例、绘图函数在笔迹上取值的方式——写在各自状态行里）：

- 只选几个对象、没有标记中心时的规则（现在取选择里第一个点；没有点则提示）；
- 方形网格只显示原点和横轴单位点（矩形网格的三个点是实测）；
- 父/子对象弹出项的动作（现在关闭对话框并选中该对象）；
- 参数选项里下拉框的内容（精度档、笔迹颜色）：原版下拉框是自绘的读不到，按常规写的；“方向度”按 -180°~180° 显示；
- 文档选项的取消会撤回增删页；用户关掉运动控制台后，下次动画仍会自动弹出；
- 路径绘点的 `[0.0 .. 1.0]` 范围提示只实测过线段，圆等路径是类推；导函数里三角函数按“度”求导（多一个 π/180）。

**当时可能影响 `.gsp` 的改动：**这一轮尚未完成坐标系、显示设置和多种构造的原版互读及写出；后续已补充多项验证和写入，直角坐标标记距离平移也已有点和非点小样本原版互读。当前保存保护、显示设置及未完成范围以[兼容性报告](兼容性报告.md)为准。
