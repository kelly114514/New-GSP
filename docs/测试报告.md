### 2026-11-07 Paint Cone 相切与按钮修复

- 复现取自用户留在后台的 473 对象课件恢复副本。画板上圆 106 的半径和圆心到直线 219 的距离均约 308.014822954 页面像素。原判别式因平方量相减变为约 −0.000011，旧容差为 0.000000001，导致 0 号交点 220 丢失。另一个切点是 1 号分支 231，旧求值只保留 0 号分支时会丢掉它。两点共同参与 Reset 目标 290 的计算。
