## 没有自动化或没有验证的部分（如实列出）

- **系统打印对话框**无法自动化：打印输出验证到 PDF 导出（`Page.printToPDF`：1 页 A4、含图像）；真实打印机未验证。
- **剪贴板**：应用内复制粘贴有测试；桌面程序里按 Ctrl+V 粘贴真实 Windows 剪贴板里的图片（PowerShell 放入 40×20 位图，Rust 命令 `read_clipboard_image` 取出）已在桌面冒烟里端到端验证（第四轮）。浏览器版的 `paste` 事件路径有单独的浏览器测试。冒烟测试会改写并最后清空用户的系统剪贴板，运行前注意。
- **中文输入法**：文本编辑使用浏览器原生 `textarea`；没有用真实输入法做端到端测试，只测了中文字符的输入和保存。
- **与原版界面的像素级对照**：几何对象整页对照已做（97–99% 重合）；文字渲染、坐标轴刻度间隔、对话框像素布局没有逐像素对照。
- **原版真实鼠标采集**（第三轮新增）：度量拖动、文本框命中范围、多边形内部命中、图片粘贴与拖动、页面增删与页名、隐藏/显示按钮选项等，样本在 `reference/raw/runtime/fixtures-v2/`；轨迹的命中范围（约 ±7 像素）、弧和函数图像（约 ±5）已实测，低/高档的半径没有。
