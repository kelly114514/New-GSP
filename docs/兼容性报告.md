## 独立复核

2026-11-09 对照当前源码和当日交付。七份含方法 96 的样例分别读取和求值，均可编辑，每份的取样图片都有定义。全库读取、求值和保存采用本报告对应章节的口径。

- **多页角度单位（2026-11-11）。** 原始记录只读扫描发现 51 份多页课件的不同页面使用不同 `10042` 值。自制双页夹具第一页设为度、第二页设为弧度：原版分别显示 `sin(30)=0.50` 和约 `-0.99`。新版现按页面读取单位、切页重算并以该单位绘制，完整重编码也逐页写入；新版写出的双页夹具经原版切页显示相同结果、另存后两个单位和标签字体斜体仍保留。原版另存把示例中的黑色对象颜色从 `#000000` 改为 `#000001`，故本验证不宣称其余所有字段逐字节一致。全库读取、保存审计和截图对照均已复跑。
- **多页默认精度与文本样式（2026-11-11）。** 自制双页夹具在原版参数选项中确认 `10040` 类别 0 是距离、1 是角度、2 是其他，此前前两项的解读相反；不同页面可各自设置。原版文本样式对话框也确认两页标题字体、字号和粗体分别生效。新版已按页读取和写回，新版重编码夹具在原版对话框中与源夹具一致，原版另存后各页设置读回一致。设置对话框现保留当前页样式、记录未保存状态，并将新建画板默认值与已打开文档隔离。
- **数学标签斜体与字体斜体。** 原版对同一自制双页夹具的“数学标签用斜体”复选框两页均显示开启，但两页标签字体的斜体分别开启和关闭；因此不能用 `10044` 的字体斜体推断该复选框。原版参数选项短暂修改实验未能确认文件记录，已恢复并复读原值。新版读取原版文件时分别保留标签字体斜体，数学标签选项继承程序设置；不能证明可写回的显式修改仍受保存保护。该选项在原版文件中的位置和完整行为仍待验证。
- **直角坐标标记距离平移（2026-11-11）。** 已写出方法 18、19、20；点、线段、圆和多边形的自制夹具经原版打开另存后定义一致，新版检查点及三种非点对象的位置一致。新版回归还验证改变距离后重新求值；其余类型及原版动态操作仍待验证。依据与记录布局见[格式笔记](gsp格式.md)。
- **边界及曲线交点（2026-11-11）。** 新版可写射线与多边形边界的分支 0 交点（方法 93），也扩展了圆与轨迹、直线与参数曲线的交点写入（方法 98）。自制 9 和 25 对象样本经原版打开另存后定义一致，由新版读回的交点求值位置一致。交换方法 93 或 98 自制样本的父对象顺序，会使原版画面中的相应交点消失；反序写出继续受保存保护。其他曲线组合及原版动态操作仍待验证。记录依据见[格式笔记](gsp格式.md)。

- **轨迹保存（2026-11-10）。** 原版样例记录中，方法 35 的点轨迹为类型 42、非点对象轨迹为类型 43；父对象可包含与驱动点自身路径不同的采样路径。新版按被驱动对象的实际类型写入，并允许独立采样路径；着色轨迹仍用方法 102、类型 90。自制 18 对象的线段路径夹具包含点、线段、圆、着色点和着色线段，经原版打开、另存后定义一致；另一 11 对象夹具让线段上的驱动点沿另一圆采样，点与线段轨迹经原版另存定义一致，原版与新版画面中的圆周与线段族目视一致。退化圆的角度范围也有新版回归；更多路径、对象类型及动态交互仍待原版验证。
- **显示设置保存保护（2026-11-10）。** 发现来源标记此前会使模型比较忽略显示精度与文本样式，完整重编码可能静默重置它们。现写入三类显示精度和已确认的文档文本样式，并比较实际值；无法确认保留的设置继续保护。自制精度 4、3、1 和两类字体样式经原版打开另存后内容一致。此前全库审计的“差异被放行”没有检查这些被忽略的字段，不能证明当时没有此类丢失。

- **三点弧的取值方向。** 原版自制夹具中，三点弧的参数 0 和 1 分别落在第一个点和第三个点；附着点和按值绘点均如此，交换端点后方向随之交换。新版原先把部分弧按绘制方向取值，现保留构造方向，平移、反射后的取点与投影也随之变化。`圆面积.gsp` 的扇形迭代恢复朝内，原版与新版单页截图按本报告口径得分 0.9798。反射弧的自制夹具截图对照得分 1.000。
- **坐标轴 π 刻度。** 解析、绘制并写回横轴和纵轴各自的 `2309` 标志。原版自制夹具验证了两个方向的标志与多种缩放的刻度间隔，新版写出的双轴夹具经原版另存后 6 个对象一致。`轨迹问题.gsp` 的静态截图得分 0.9776。不同缩放下的全部刻度规则和自动吸附仍需原版实测。
- **格点与吸附。** 页级自动吸附和坐标系格点显示已分别读取、写回和切换；无坐标系的页也保留吸附标志，旧 `.ngsp` 中的 `sys.snap` 保持兼容。原版自制夹具确认方形网格吸附，两个标志同时开启的新课件经原版另存后均保留。浏览器回归覆盖菜单、撤消和吸附；π 轴吸附与极坐标格点布局仍待原版验证。
- **字体与文本框。** 自制微软雅黑文字夹具以及冻结验收文件 `00-全部对象.gsp`、`12-n-text.gsp` 的临时副本经原版打开另存，Microsoft YaHei 和宋体变为 Tahoma，Arial 保持不变；此前完整互读结论没有覆盖字体。新版新建文字默认改为 Times New Roman，对已确认会被原版替换的字体拒绝无损 `.gsp` 保存并支持转存 `.ngsp`；用户已有的字体设置不强制更改。文本框编辑结束时按原版整数页面像素存宽高，避免浮点尺寸造成保存保护误拒绝。
- **文字字号。** 原版六档自制文字的绘图区字形宽高与 `#` 后十六进制数对应的逻辑像素字号吻合；此前额外乘以 96/72 导致分段文字偏大。现按原数字读写，`0109`、`0108` 和 `1372` 等课件的文字对照改善。旧 `.ngsp` 仍按其记录的字号显示。
- **分段文本和公式。** 新版可写分段字体、颜色及引用，动态数值显示保留对应字体；支持分数、上下标、根号和括号的结构。新版写出的自制课件经原版打开、另存，文字、引用、样式和上述公式结构读回一致；普通文本框尺寸由原版重算。已有来源的 5.x UTF-8 简单无引用文本可在保留其他记录的情况下编辑并写回，旧版或非 UTF-8 来源、复杂来源和未知标记仍受保护。 组合文字中的按钮按原版显示为文字，不再额外画框，点击范围继续保留。
- **轨迹间断与边界。** 原版自制夹具显示，参数驱动的横向阶跃约 25.7 页面像素时连线、约 26.5 像素时断开；改变采样数（40、500、1000）不改变结果，陡峭连续直线仍连线。斜向阶跃结果表明判定与单轴距离有关。新版先检测突变候选，再二分检查是否持续跳变；每个有定义区间的端点也做二分细化（每条轨迹最多 64 个边界，每处 8 次）。低采样平方根夹具显示原版会接近定义域边界。“蚶线.gsp”此前的跨分支竖线已消失，外圈缺口明显缩小。此算法含基于夹具推导的启发式，并非已证明覆盖全部原版边界。
- **迭代末点。** 轨迹只需迭代象末点时，倒序求最后一个可显示对象，避免展开整组迭代象。逐样本与完整展开测试覆盖单映射、多映射和最终迭代。后续的数值快路径见[迭代数值快路径](#迭代数值快路径)。
- **读取附着文字。** 读取时仅求文字锚点和依赖，避免为定位文字先计算整页。`tools/check-anchor-decode.ts` 用旧的全页求值方式逐份对照 1,431 份课件，解码内容快照全部一致。`Mira分形-三鹰翅.gsp` 在本机一次测量中读取阶段由约 85 秒降至约 14 毫秒；两次测试的并行负载不同，不能把比例当作稳定基准。后续整页求值测试见[迭代数值快路径](#迭代数值快路径)。
- **方法 96 组合和保存。** 原版夹具先平移图片再施加坐标映射时，新版此前误建无定义的点。现沿内置变换链识别图片，生成取样图片，并支持写出图片平移。原版打开新版写出的组合样本、另存，18 个对象读回一致。用 `warp-native.gsp` 修改采样数和失真度时，正式入口保留原记录并写成 `.gsp`，原版打开另存后 14 个对象读回一致。相关回归见[变换构造](../src/core/construct.ts)和[图片测试](../tests/custom-image.test.ts)。

- **截图评分。** 脚本现以原版截图中最常见颜色估计背景，用同一背景统计两幅图与其相差超过 60 的前景。样例 0492 得分为 0.511。背景估计不适合所有可能的全屏图案，背景色本身也单独记录。见[评分脚本](../tools/compare-library.py#L19)。

## 迭代数值快路径

2026-11-11。目标是只提速、不改结果：Mira分形-三鹰翅.gsp 的着色轨迹有 500 个采样，每个采样做 9,999 层单映射迭代，旧代码对每层的每个对象都走通用求值（分配 Q、Result、Map 查表）。

做法（[engine.ts](../src/core/engine.ts) 的 `evalSingleMapLastIterPoint`、新增 [iterfast.ts](../src/core/iterfast.ts)）：

- **只留末状态。** 轨迹链里读取这个迭代的只有迭代象、迭代象又只被迭代点读取时，缓存里不再保留 9,999 层状态；各迭代象的末点在末状态上都核对过，任何一个在末状态上求不出末点（原本要往前找前一层）就回到完整保留重新求值。
- **数组式查表。** 迭代体里用数组和代数戳代替每层新建 Map 和 `memo.clear()`。
- **数值编译。** 迭代体只含“计算（含用户函数调用）/ 横纵坐标度量 / 按坐标画点”、无单位、没有位置覆盖时，编译成对 `Float64Array` 的直接运算（度制和弧度制均支持）。运算顺序和舍入与 `expr.ts` 的求值一致；中途出现无定义、非有限数、坐标系退化、单位不是无单位、对象或函数定义被替换等任何不寻常情形，立刻退回通用求值器从当前层继续，所以边界行为不变。反三角函数（结果带角度单位）、极坐标绘点、导函数、函数递归都不在快路径内。

核对：

| 项目 | 结果 |
|---|---|
| `Mira分形-三鹰翅.gsp` 完整结果的 SHA-256（`JSON.stringify([...result])`，与上一轮优化前基线同一口径） | 优化前后均为 `3cf3ac79bacaefabccecf9fc5d08babcd7c96c4a4936058f963b95584e9dbf0a` |
| Node 单次整页求值 | 快路径后 esbuild 打包版约 2.4 秒；早期约 67.7 秒来自 `tsx` 加 CPU 剖析，运行方式不同，不能直接计算提速比例 |
| Chrome 源码模式整页求值（`tools/perf/mira-browser.ts`，同次关闭与开启） | 约 25.7 秒 → 约 5.5 秒，114 个对象的完整结果 SHA-256 一致；当时并行运行另一项 CPU 剖析，非稳定桌面基准 |

## 通用迭代与交点求值

2026-11-11 对多映射、大量迭代象的课件，密集对象编号使用数组保存每个迭代状态的对象结果，稀疏或异常编号仍用原来的 Map；同时把交点求值里不依赖调用状态的函数移出热循环。没有改变迭代层数、采样数或几何公式。

`IFS-4_circles_limit_set__4.gsp`（156 个对象，240,000 个迭代图形）用同机 Node 打包版单次测得整页求值约 4.96 秒降到 2.44 秒，优化前后逐对象指纹一致；测试负载有差异，该数字不是稳定基准。数组查表修正后、交点热循环调整前，Chrome 源码模式下移动自由点 36 的三个位置，每次只重算一次，分别约 3.07、3.34、3.09 秒；最终位置的 240,000 个图形及完整结果 SHA-256 与同位置完整重算一致。浏览器测量时有整库验证并行，不包括真实桌面输入、绘制或显示刷新；交互性能仍需继续优化。复测脚本见 `tools/perf/mira-bench.ts` 和 `tools/perf/ifs-browser.ts`。

数组查表和交点热循环调整后，以修正重复重算的调查脚本复核全库 2,421 个非空页面，其中 2,352 页模拟移动自由点；打开及移动后的聚合结果 SHA-256 为 `702a4b8b482394495a53be537ebfb4e9e7e953a20ad91164e46d3dced6aeb3a4`，与改动前一致，0 页报错。并行测试时，单次移动重算中超过 100 毫秒的有 284 页；结果受负载影响，不包含绘制和真实鼠标输入，不能直接视为用户实际帧率。
