## 2026-11-06 保存完整性修复（当前结论）

详见 [保存完整性修复](保存完整性修复.md) 与 `roundtrip-report.json`。1431/1431未修改课件逐字节另存；1139份可编辑课件中758份低层编码拒绝、381份可编码，其中330份存在模型差异、51份模型一致。正式保存入口没有放行任何已检出的模型差异；修改过的导入文件，已知自由点/外观定长字段可保留源记录写回，其它编辑必须通过来源逐字节重建检查，以保护未解码信息，否则提示改存当前模型为 `.ngsp` 并保留原文件。

### 互读中发现并修复的问题

- 原版拒绝**带引用的计算同时有位置记录（2211）**的文件：二分实验定位后，写入器对带引用的计算不写 `2211`。
- 原版另存时会按计算结果的单位重写计算的类型号（无单位 51、距离 48、角度 49）：写入器改为依结果单位写。
- 参数的数值是令牌而不是 f64（见 `docs/gsp格式.md` §4）：用不同数值的样本（7、2.5、−4、12）对照得出。

## 3. 保存与保护策略的验证

| 场景 | 结果 | 用例 |
|---|---|---|
| 无修改的导入文档另存 | 逐字节原样输出 | `app.save` 与 `encodeFile` |
| 含未知对象的文档 | 只读：拖动、构造、删除一律拒绝并说明原因；不会丢弃未知对象后继续保存 | `engine.test.ts`「只读保护」 |
| 含没有写入依据的对象（文本、表格、图片、带函数调用的计算等） | 保存时明确提示，可改存 `.ngsp`（完整无损，仅新版可打开） | `codec.test.ts`、`demo.test.ts` |
| 截断或损坏的文件 | 给出错误，不崩溃 | `codec.test.ts` |
| 中文路径 | 在真实 Tauri 窗口里打开、编辑、保存、读回 | `tools/desktop-smoke.ts` |
| 保存失败 | 同目录临时文件 + 写后回读校验 + 原子替换；失败保持原文件和未保存状态；Rust 单元测试覆盖“校验失败不替换” | `src-tauri/src/main.rs` 测试 |
