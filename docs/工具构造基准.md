# 工具构造同输入基准

`npx tsx tools/make-tool-baseline.ts` 读取本机工具文件夹，使用固定种子 `123456789` 和 `tool-input-fixture.ts` 生成合成输入，在新版重放工具，筛选低层编码可写的40个工具；每个保存初始与移动第一个自由点两个状态，写到新建系统临时目录。可传工具文件夹路径作为第一个参数。不会启动原版，也不将原始工具数据放入项目。

清单记录工具来源、零起索引、输入种类、构造类型、依赖、每对象定义与求值摘要、可见无定义对象，以及低层编码前后全部模型差异。长结果数组只记录长度和前16项。编码可执行不代表模型无损，另存结果应首先与清单里的 `encodedModel` 比较。此方法验证新版重放所生成的构造能否被原版打开和另存，不能验证原版工具界面调用及工具段互读。

原版另存到单独目录并保留相同文件名后，运行 `npx tsx tools/check-tool-baseline.ts <基准目录> <另存目录> [报告路径]`。报告比较两份文件经新版解码的模型和求值，分为缺失、解析失败、定义、数值、外观或设置、相同；浮点相对容差为 `1e-6`。长数组只比较前16项，结果不是原版运行时的数值，也不是像素比较；定义或数值告警需要排查原版规范化、新版编码和解码等原因，不能直接定为原版错误。

2026-11-06 本机生成40个工具、80份文件，覆盖40个组、13种输入和38种构造定义；50份存在编码前后模型差异，8份存在可见无定义。将输入目录与自身比较得到80份相同，用于验证比较脚本的基本路径，不是原版验收。
