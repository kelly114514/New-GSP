# GSP 文件格式笔记

本文件是新版读写 `.gsp` 的依据。每条结论都标明**怎么得到的**：

- **[原版样本]**：用原版程序（`reference/raw/runtime/create_fixtures_v2.py` 驱动，只发窗口消息）在新建空白文档里做出对象、另存到系统临时目录，再读记录得到。样本副本在 `reference/raw/runtime/fixtures-v2/`（开发参考，不随软件发布）。
- **[互读]**：新版写出的文件在原版中打开、另存，再由新版读回，对象逐个一致（`tools/check-interop.ts`）。
- **[样例统计]**：对 1431 个原版样例的统计（`npm run scan`）。
- **[推测]**：未经原版验证，写入器**不使用**。

## 1. 文件与记录

- 文件以 ASCII `GSP4` 开头，后面是小端记录 `[u32 长度][u32 标签][数据]`。
- 汉化版有些记录的声明长度比实际少 1：在声明位置之后不是可识别的记录边界、而加 1 后是边界时，按加 1 读（`src/gsp/records.ts`）。[样例统计]
- 整体结构 [原版样本]：`900` 签名、`902` 兼容性说明（两个，内容是一段提示长文，写入时用自己撰写的短提示）、`1006/1007/903`；每页：`902`、`1000`（页头，偏移 24 的 u32 是对象数）、`2400–2419` 与 `2399`（标签计数）、页设置类记录（`10002…10044`、`9004`、`9008`、`1201/1203`，**可省略**）、对象、`1001`、`903`；最后 `901`。
- `2400–2419`：每条 6 字节；`2401` 的第一个 u16 是本页**点标签已分配个数**（删除点后字母不回收），`2402` 是线型对象的标签计数。
- 对象 = `2000`（28 字节头）→ 可选 `2002`（父对象）→ 可选 `2003`（参数）→ 可选 `2005`+`2008`（标签）→ 其它数据记录 → `2007`。父对象序号是 **1 起始的、页内对象序号**，且必须在被引用者之后。

## 3c. 第三轮补充 [原版样本][互读]

每一条都有对应的原版样本（`reference/raw/runtime/fixtures-v2/`，括号里是样本名）和 `tests/codec.test.ts` 里的逐记录比对；写出的文件另在 `interop-all.gsp`（97 个对象）里经原版打开、另存、读回一致。

- 移动按钮可包含多组 [源, 目标]；每组都会执行。自由点、路径点、参数、坐标系单位点分别按自己的约束移动。路径点投影回路径，参数取目标数值。动画的自定义正数速度不再拒绝，但数值速度与原版实际时间单位尚未动态标定。

### 保存与验证边界

807 个工具均可解析和重放，不代表任意输入都有几何结果。退化图形、零除、平方根定义域、错误单位等可得到 `undefined`；不应把“有 Result 条目”统计成“求值成功”。本轮合成输入审计要求全批对象无未知定义、无缺失引用、无 `missing/unsupported`，并逐工具 `.ngsp` 写出读回比较定义及结果；另有界面、桌面重放回归。

发散迭代可以产生极大的有限坐标，这仍按数学结果保留；新版只在绘制和滚动布局上裁剪/限制，避免原生绘图器内存耗尽。轨迹取样上限 5000，原版取样上限尚未确认。

新增定义都能完整存进 `.ngsp`。`axis-line`、`axis-unit`、`custom-point`、`angle-mark` 等尚无全部 `.gsp` 写入路径，保存时沿用明确提示改存 `.ngsp` 的策略。新增可写构造（例如方法 75、80）的**原版互读尚未补做**；不能拿新版写出再读回代替原版互读。创建工具、自动匹配假设和脚本视图的未完成项仍按 §3h 与规格入口清单保留。

## 4. 参数、计算、函数的令牌流（2311）[原版样本][互读]

`2311` 是 22 字节文本头（`<0>`）加载荷，**数值本身不存成 f64，而是存成令牌**：

- 令牌（u16）：数字 `0–9`、小数点 `0x0a`、`(` `0x0b`、`)` `0x0c`、变量 x `0x0f`；`+ − × ÷ ^` = `0x1000…0x1004`（减号同时做负号）；引用第 i 个父对象 = `0x6000+i`；度 `0x0101`、厘米 `0x0201`。
- 令牌数组在记录末尾，个数在记录偏移 44 的 u16；载荷长度字段（偏移 36）= 60 + 令牌字节数。
- 参数在偏移 70 起有 5 个 f64：无单位 `[步长(整数 1，一位小数 0.1) −100 100 1 1]`；角度 `[5°弧度 0 2π π/4 1]`；距离 `[1厘米像素 0 3862.3 1厘米像素 1]`。
- 计算/函数此处是 40 字节原版残值，写入器填固定形状的数据（互读通过）。
- **带引用的计算不能带 `2211`（位置记录）**，否则原版拒绝文件 [互读，用二分实验定位]；无引用的计算和参数有 `2211` = 显示框 `[左,上,右,下]` u16。
- 计算的类型号随**结果单位**变化：无单位 51、距离 48、角度 49（原版另存时会按结果重写）。
- **函数调用令牌** `0x2000+n`，后面跟自变量，以 `)`（`0x0c`）结束。13 个内置函数按菜单顺序：`sin cos tan arcsin arccos arctan abs sqrt ln log sgn round trunc`。[原版样本：`reference/raw/runtime/fn_tokens.py` 用真实鼠标点函数弹出菜单的每一项，再用画板截图核对数值得到]
- 原版默认角度单位是**度**：无单位的数传给三角函数也按度算（`sin(0.5) = 0.01`，`cos(0.5) = 1.00`）；反三角函数返回度。新版同此。
- 引用自定义函数 `f(x)` 的令牌、`sec csc cot exp` 没有样本，写入器拒绝（改存 `.ngsp`）。

## 5. 保存策略

- `encodeFile` 对导入且未改动的只读文档直接输出原始字节。
- 其它情况用 `encodeGsp` 重建；遇到没有样本依据的对象抛出 `Unsupported`，**不会丢弃它后继续保存**。写后再用读取器完整读回并核对对象数。
- 无法写成 `.gsp` 的课件可改存新版课件 `.ngsp`（`NGSP1\n` + JSON，完整无损，仅新版可打开）。
- 桌面版写同目录临时文件，写后回读校验，再原子替换（`src-tauri/src/main.rs`）。

- **同页多个点型迭代象按迭代层交错绘制。** 1131（六色圆极限集）的原版画面里，先出现的白点盖在后出现的彩色点上，绿点只留在绿色的簇里。受控对照三种叠放方式的彩色得分：按对象顺序 / 反序 / 逐层交错，1135 为 0.902 / 0.940 / 0.952，1131 为 0.736 / 0.715 / 0.760，1006 为 0.884 / 0.902 / 0.904，其余课件不变。逐层交错采纳。
- **度量、计算和参数的文字画在文件位置右下方。** 左 4 像素、上 5 像素（0669、0416、1162、1346、0454、0813 的墨迹外框差全部落到 ≤1 像素）。
- **十进制坐标轴的刻度。** 把 0813 的单位点位移改成 3…1000 像素，取消轴对象隐藏，原版画出：数字取 1-2-5 序列里间距大于 80 像素的最小值（纵轴约 40，按 1221 的画面推定），刻度是数字步长的 1/10（尾数 1）、1/4（尾数 2）、1/5（尾数 5）。例：单位 100 像素时数字每 1、刻度每 0.1；单位 45 时数字每 2、刻度每 0.5；单位 3.16 时数字每 50、刻度每 10。刻度总长约 10 像素。单位 4 像素的夹具取了恰好 80 像素的间距（20），其余恰好 80 的单位（8、16）都被舍掉，属单点不吻合。纵轴阈值只靠 1221 的画面推定，未做纵轴夹具（0813 的纵向单位不是一个独立的 f64）。π 刻度轴没有改。
- **随机迭代里的随机前像，路径要在本层的状态下重算。** 0813（蒲丰投针）的前像 C[2]、X[1] 选随机位置后，针尖 F[2] 在“以 U[1] 为圆心、针长为半径”的圆上随机取点，U[1] 由本层刚选出的 C、X 决定。此前新版用第 0 层的圆，所以每层的针都从新的 U 指向旧圆上的点，成了从中心放射的长线。现在按前像次序依次选取，路径依赖前像或迭代体内对象时在已更新的状态下重新求路径。随机序列本身仍与原版不同。
- **混沌迭代的验证（1262）。** 把 n 改成 10、50、500、5000、50000（令牌流同位数补 0），原版与新版在 n ≤ 500 时逐点一致，n = 5000 开始形状分叉，n = 50000 差别明显。这是数值混沌放大舍入差异，不是公式语义错误，所以不再追求逐点复现；n = 100000 时新版还受 6 万状态上限限制。

**已试、结果不理想而未采纳：** 迭代象整体反序叠放（1131 变差）。
**未解决（新发现）：** 0813 的两个标题文字（红色在前、绿色在后）原版是红色压在绿色上、只露出一圈绿边，并且原版画的是常规字重而新版画粗体；原版“靠前的在上”是否对所有文字对象成立未验证。

补充（同一轮的其余规则，依据见[兼容性报告](兼容性报告.md#第十七轮)）：

- **点轨迹压在直线、圆、弧下面（经验规则）。** 0669 里深红的点轨迹（类型 42，大类 6）被蓝色线段和绿色弧线盖住。受控对照：只改绘制次序（轨迹先画）后，在 420 份带轨迹的课件里 8 份彩色得分提高、2 份降低（0837 里弧的轨迹压在绿弧上，现在多露出一道绿边）。只对“点轨迹”先画的方案更差（0291 变差），所以用“全部轨迹先画”。原理未明。
- **坐标系的 `unitY` 可能是计算对象。** 用“单位长度”度量定义坐标轴时（0870），`unitY` 指向计算，不是单位点；解码时只对点类对象设置纵轴单位点的隐藏状态。
- **文字引用另一段文字。** 引用的文字自己含 `U+E000 序号 U+E001` 标记时，先展开再嵌入（0870 的“矩形DEFG的面积”）。
- **度量文字。** 负数写成 `–`（短横线，U+2013），长度单位紧跟数字（`0.60厘米`），文字里嵌入的数值和表格沿用旧写法；乘方的底数是加减乘式时只加一层括号。
- **迭代的上限。** 单映射原版夹具测得 100,000 层。多映射用 46 和 47 个映射的夹具测得原版预算在 99,498 至 106,078 个非初始状态之间，超限保留到最后一个完整层。新版采用 100,000 状态。
- **第十七轮性能及动画。** 1130 点型迭代象直接复用映射，浏览器完整重算 487 ms，拖动重算和完整重算指纹相同。1226 的极角和反三角函数按编译期推导的单位求值。`probe_anim_speed.py` 在原版量得线段及圆上的三档速度约为每秒 35、105、175 页面像素。参数速度、自由点变向规律和追踪衰减仍需独立验证。
- **奇数线宽的直线对齐像素。** 原版（GDI）画 1、3、5 像素的直线是对齐像素的实线，端点取整后落在像素中心；新版只在画布缩放为 1 时这样做（四舍五入取整，取下整更差），缩放或高分屏时保持精确位置。
- **`10002…10007` 里除 `10005` 外的含义仍未知**，`10006`、`10007` 改写后画面无变化。
