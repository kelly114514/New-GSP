# 新版 使用说明（0.1.0）

新版是一个独立实现的动态几何软件，菜单、快捷键和鼠标操作沿用原版的习惯，并能打开、保存原版 `.gsp` 课件中的常用内容。

## 安装与启动

- 运行 `新版_0.1.0_x64-setup.exe`，按提示安装（当前用户安装，不需要管理员权限）。需要 Windows 10/11 和 WebView2（Windows 11 自带）。
- 也可以直接运行 `new-gsp.exe`（release 程序，免安装）。
- 卸载：开始菜单里的“卸载”，或设置 → 应用。

## 基本操作

| 想做的事 | 怎么做 |
|---|---|
| 画点、线段、圆 | 点工具箱图标；线段/射线/直线、多边形各有三个子工具：**按住图标约 1 秒**弹出，松开在想要的子工具上 |
| 选择 | 单击对象加选，再次单击取消；单击空白清除；Shift+单击空白保留选择；空白处拖动框选（碰到就选） |
| 移动 | 拖动点；拖线段中间整条平移；拖圆心移动整个圆；拖圆上的点改半径；线上的点沿线滑动 |
| 交点 | 用箭头在两条线相交处单击，当场生成交点 |
| 撤消 / 重做 | Ctrl+Z / Ctrl+R；一次拖动是一步 |
| 标签 | 选中后 Ctrl+K 显示；标签按**选择顺序**分配字母，删除后不回收 |
| 构造、变换、度量、数据、绘图 | 对应菜单；不可用的命令是灰的，名称会随选择变化（如“隐藏线段”“线段上的点”） |
| 平移/旋转/缩放 | 先选点“标记中心”，再选对象；对话框里选固定值或已标记的值 |
| 度量坐标 | 第一次度量坐标会自动建立坐标系；按住 Shift 打开“度量”菜单可见“横&纵坐标” |
| 函数 | Ctrl+F 新建函数，Ctrl+G 绘制新函数；表达式里可用 `+ - * / ^`、括号、`pi`、`sin cos tan arcsin arccos arctan sqrt abs ln log exp` 等 |
| 动画 | 选中路径上的点或参数，“显示 → 动画”；“运动控制台”可加速、减速、停止；暂停不会改变构造 |
| 追踪 | “显示 → 追踪”，擦除用 Shift+Ctrl+E |
| 按钮 | “编辑 → 操作类按钮”：隐藏/显示（默认是切换：隐藏后按钮变成“显示”）、动画、移动（四档速度）、链接（跳页或网址）、滚动、系列（同时/依序执行多个按钮）；用箭头工具单击按钮即可执行（拖动是移动按钮） |
| 多页 | “文件 → 文档选项”里增加空白页/复制页；底部出现页标签 |
| 多文档 | 文件 → 新建；窗口 → 平铺窗口 / 层叠窗口 |
| 打印 | 文件 → 页面设置 / 打印预览 / 打印 |
| 文本 | 文本工具：拖出文本框或双击；点框外结束；“显示 → 文本工具栏” |
| 图片 | Ctrl+V 粘贴剪贴板里的图片（按原始像素大小放在左上角，统一存成 PNG）；选中图片和多边形内部后“编辑 → 剪裁图片到多边形” |

## 文件

- **打开**：`.gsp`（原版课件）、`.ngsp`（新版课件）。
- **保存**：未修改的导入 `.gsp` 逐字节保存。修改后，自由点位置与部分外观可保留源记录写回；其它编辑只有通过来源信息保持与模型完整性检查才写 `.gsp`；否则提示转存**新版课件 `.ngsp`**，取消时仍标为未保存。当前限制包括显示设置、标签偏移、部分文字位置/尺寸，以及部分文本、交点、坐标轴、表格和图片等内容；以实际提示为准。`.ngsp` 保留新版当前文档模型，只能用新版打开；尚未读取的原版信息仍需保留原 `.gsp`。
- **只读打开**：原版课件里如果有新版暂时读不懂的对象，课件会按只读打开：可以查看、演示，不能编辑；不修改时“保存/另存为”会逐字节原样保存。这样不会因为新版不认识某些内容而损坏你的课件。
- 保存时先写同目录临时文件、写后回读校验，再替换原文件；失败时原文件不变，文档仍标记为未保存。

## 恢复

- 新版每 20 秒把有未保存修改的文档写成**恢复快照**（新版格式，存在应用数据目录 `…\org.example.newgsp\recovery\`，不是 `.gsp`）。
- 程序异常退出后重新打开，会提示“找到了未保存的恢复内容”，选择“确定”即可在新窗口里恢复，标题带“（恢复）”，之后请另存。
- 正常关闭或保存后，对应快照会被删除。

## 设置

“编辑 → 参数选项…”：选择能力（低/中/高，命中半径 10/15/21 像素）、新建多边形是否显示边界、双击取消选定、新建点自动显示标签、编辑文本时显示文本工具栏。设置保存在本机，下次启动继续生效。

## 迭代

1. 先做出前像和依赖它们的对象（例如两个点 A、B，线段 AB，中点 M）。前像可以是自由点、路径上的点、参数或计算结果。
2. 选中前像，执行“变换 → 迭代…”。面板浮在画板右上，不挡画板：在画板里依次单击对象，给每个原象指定初象（例如 A→B，B→M）。点对点、数值对数值。
3. “显示”菜单：增加/减少迭代（面板里也可按 `+`、`-`）、完整迭代（显示每一次）、最终迭代（只显示最后一次）。“结构”菜单：添加新的映射（Ctrl+A）、删除当前映射、所有对象的象、仅保留非点类象；有多个映射时默认只保留非点类象。“生成迭代数据表”已支持；“移动原象上的点到相对类似/随机位置”尚未实现。
4. 点“迭代”。依赖前像的、可见的对象各得到一个迭代象；之后右键迭代象可以“增加迭代/减少迭代”。
5. **深度迭代**：先选前像，**最后**选一个参数，按住 Shift 再打开“变换”菜单（命令名变成“深度迭代…”）。次数取自这个参数，改参数的值就改变迭代次数。
6. 没有依赖所选原象的对象时会提示，不会打开面板。次数上限 10 万、状态数上限 10 万（原版课件可迭代 10 万次，5 个映射迭代 7 层有 97,656 个状态；原版真实上限未知，超过的部分不显示）。

## 自定义工具

- 工具箱最后一个图标（自定义工具）按下弹出菜单。**选择工具文件夹…**：选原版的 `Tool Folder`（或任何放有工具文件的文件夹），新版会读出里面的工具，可以顺便复制一份到新版自己的文件夹，之后不再依赖原路径。按住 Shift 打开菜单，最后一项变成“忽略工具文件夹”。
- 工具按文件分组，指向组名出现该组的工具。**灰显的工具暂时不能用**，鼠标悬停有原因（工具里有新版还没读懂的对象，或某种前提条件的点选规则还没有核对）。随本轮验证的原版工具库为 **807 / 807** 个可识别、可调用；其它工具文件仍按实际定义检查，详见 `docs/工具兼容报告.md`。
- 选一个工具后，在画板上依次点它的前提条件：要点时，点已有的点，或在空白处/线上单击新建；要数值时，点已有的参数、度量或计算；要线段、路径、函数等时，按状态栏提示点相应对象；坐标系可通过原点或坐标轴点选。点齐就重放，一次应用是一步撤销。工具会一直保持选用，直到换别的工具或按 Esc。
- **创建新工具…**：选中要做成工具的对象，起名保存到当前文档。独立自由点和参数是前提条件，其余依赖成为隐藏的中间步骤。**工具选项…** 打开文档选项的“工具”页，可以删除文档里的工具，或从已载入的工具文件夹复制工具过来。将旧版式工具复制到文档后，请使用 `.ngsp` 保存。
- 创建工具时，独立自由点和参数可作为前提；调用现有工具支持路径、线、函数、坐标系等输入。属性中的“在自定义工具中使用标签”可让创建的工具保留该对象标签。选择工具后，可从工具箱查看对象及依赖清单，也可主动匹配所选对象：每个前提必须有唯一候选，存在歧义时请逐一点选。这些是新版规则，尚未与原版对照。部分输出不能写成原版 `.gsp` 时，请按提示改存 `.ngsp`，这样能完整保留构造。
- 编辑文本时可选中一段后用文本工具栏设置字体、字号、颜色和粗体等；结束编辑后在画布显示局部样式，编辑框内暂以统一字体显示。分段样式须保存为 `.ngsp`；原版富文本的分段导入和含嵌入对象文本的局部样式显示仍待完善。

## 本版暂缓

网页导出，以及原版附带的在线服务入口；迭代里的“移动原象上的点”选项。菜单里保留了它们的位置，命令是灰的，鼠标悬停有“本版暂缓”的说明。

## 已知限制

见 `docs/兼容性报告.md` 和 `docs/进度.md`。最主要的两条：

1. 原版课件的读取覆盖、只读保护和保存检查，见 [兼容性报告](兼容性报告.md)。
2. 原版局部文本样式、图片变换、剩余页面对象及工具逐个输出对照尚未全部完成；详见 `兼容性报告.md`、`保存完整性修复.md` 与 `进度.md`。

## 本轮新增及边界

图片可旋转/反射并保留动态来源和裁剪；选中有色笔迹图片可“定义图片函数”，白色/透明区域不参与取样，取样规则为新版算法，未认证原版一致。导函数随原函数定义修改而变化；这两类关系目前完整保存请用.ngsp。

局部样式可对编辑选区设置，画布会逐段显示；编辑框内部仍显示统一字体，真实中文输入法尚需人工验收。旧课件中的嵌套样式现在会尽量保留，不能完整写回时提示转存。最新兼容及未完成内容见《P1/P2实施与验收》。
