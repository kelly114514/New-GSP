# 原版差异审计覆盖清单

本清单用于追踪审计覆盖，不以功能存在或自动测试通过代替原版逐场景对照。“部分”表示仅有下列明确列出的场景，未列出的状态均待核对。结果和复现条件记在 `原版差异审计.md`；原版独立行为与采集方法见 `../../reference/spec/`。新版对照须标明二进制或源码版本。

| 范围 | 状态 | 已覆盖或已有证据 | 尚需覆盖 |
|---|---|---|---|
| 空白窗口和工具箱 | 部分 | 空白窗口外观；圆和线段工具两次单击 | 各子工具弹出条、尺寸、焦点、光标和不同缩放；工具切换与边界 |
| 菜单和快捷键 | 部分 | 数据菜单访问键、方向键；参数曲线空白入口；原版 42 个选择场景的规格；暂缓命令源码清单 | 每个顶层及子菜单、访问键、快捷键、Shift、不同选择和页面状态；动态文字、勾选、执行结果 |
| 对话框 | 部分 | 参数选项、新建参数、计算、函数、文档选项、单点属性及变换、页面设置与打印预览 | 所有其他对话框的默认值、禁用状态、操作、取消与提交；各选择条件和设置持久性 |
| 右键菜单 | 部分 | 空白菜单、单自由点和线段菜单及属性、单圆菜单；原版多对象类型菜单规格 | 其他点、路径、圆的动作、弧、内部、数值、文本、图像、按钮、函数、表格、迭代象和多选；逐项动作 |
| 选择、构造和拖动 | 部分 | 两点线段与中点快捷键；线段和圆工具两次单击 | 命中、吸附、选择叠加和框选；其余构造、退化输入、拖动、撤销重做、对象依赖 |
| 度量、计算和函数 | 部分 | 两点距离标签、三自由点角度及拖动更新、计算对话框引用度量；函数对话框入口 | 其他度量结果、单位、精度、引用、更新、表达式与错误；函数绘制及域 |
| 变换与迭代 | 部分 | 无标记单点平移、旋转、缩放入口；迭代历史记录 | 多对象、标记参数、结果与预览、退化输入；迭代选项、上限和动态结果 |
| 坐标、网格和绘图 | 部分 | 参数曲线和绘制点的空白入口；矩形网格点的显示和拖动；定义坐标系的初始显示；无轴、已有坐标系及单线段或单圆选中时给定数值绘点入口 | 坐标系重定义、各网格、吸附、提交绘点及其结果、选中不同轴或其他路径、函数图像、参数曲线和动态变化 |
| 页面、文档和窗口 | 部分 | 单页文档选项；原版多文档规格 | 多页增删复制、切换和取消语义；多文档激活、窗口布局、标题和保存提示 |
| 动画、按钮和追踪 | 部分 | 空白控制台入口、线段上点启动动画后的控制台；动画历史状态 | 各按钮配置、动作、速度、暂停和反向、控制台、多个目标、追踪与清除 |
| 文件兼容 | 部分 | 历史样本扫描、有限互读和像素对照，见 `兼容性报告.md` | 未知对象、每种可编辑与不可编辑场景、写回信息保持、异常、跨版本互读；重新核对统计口径 |
| 文本、图片、样式和打印 | 部分 | 属性入口、空白及单点打印预览；历史未支持项 | 文字编辑、分段、嵌入数值、图片剪裁和变换、样式、非空及多页打印输出 |
| 恢复、异常和辅助输入 | 未完整对照 | 新版有恢复、只读保护与错误处理的历史测试 | 原版对应行为、损坏文件、保存失败、中文输入、键盘可达性；避免修改用户数据 |

逐项完成要求：记录双方版本、前置条件、操作、观察结果、证据来源及未覆盖边界；涉及全局设置时按仓库规则恢复并复核。用旧规格或源码推断的项保持相应证据标签，必要时以运行界面复验。不可穷举的输入空间应采用明确的状态划分与代表性、边界及异常用例，并保留无法验证的条件；不能据此宣称所有潜在差异均已发现。
