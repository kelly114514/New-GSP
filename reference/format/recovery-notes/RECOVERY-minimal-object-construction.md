# 最小对象构造入口

`construct_minimal_loaded_object32` 是完整原构造器 `00441DE0` 的有明确准入条件的
生产适配，不计作完整原函数恢复。它支持自由点、两点线段及中点所用的真实
原生布局、父向量拥有权、内联内部标签、样式和页面链表。

## 支持条件与布局证据

输入为现有头转换器输出的30h字节 `ObjectHeaderPrefix32`。支持的原生
`constraint/kind/genera/parent-count` 为 `0/1/4/0`、`2/2/14/2`、`1/1/11/1`。
原约束表位于 `00651980`，kind和genera分别来自行+4/+8；主类型表位于
`0064E7E8`。所选kind1/2的+24构造回调确实为空、+60默认样式类别确实为零，
这些数据由普通fixture提取器逐次核验，不是成功回调替身。

当前页必须匹配传入页、`006BA20C=0`、有效当前arena，页+560必须非零。
最后一项选择原构造器的真实分支：暂不调用其末尾的+4C回调/`004444F0`。
入口不会静默跳过该调用：若+560为零会在修改前返回wrong_context。
该字段仅按已观察分支解释，不把它擅自重命名为完整加载状态。

本入口只支持field08为0/1、无额外/属性向量及显式标签payload、内部标签计数
1..999。父向量必须是当前arena中的有效原生记录，父对象必须属于该页并具有
所选构造要求的kind。外部文件读取器还必须明确拒绝未支持的记录，不能将它们
丢弃后调用本入口。其它条件在修改或取得父向量拥有权之前拒绝。

## 实际执行路径

1. `00440E50` 真实分配并初始化公共对象。分配失败时按原构造器释放已接收的
   父向量；原型内容不会被当成最终GSP payload保存。
2. `00441920` 转移AC并建立反向B0子边。首次追加失败会清理；部分追加后的
   原版无限回滚行为仍由该函数保留，不记为成功失败清理。
3. 写入原生genera，清零原构造器实际写入的60h..7Dh，再运行 `00441BE0`
   的真实默认样式初始化。
4. 按 `00460120 → 0045FDD0(mode=1) → 0045FC40` 的可达路径生成内部短标签。
   资源来自已核验中文RT_STRING4388，即 `#%d`。kind1/2分别使用页
   `+2A0+kind*12+8` 的计数，计数递增后生成 `#1..#999`。
   这些字符串在原生30h联合区内联存放，38h为零，无独立堆标签分配。
   40h为1、3Ch为零、7Ah为FFFF。原路径的 `00445AE0 → 00461290` 在
   fresh对象44h为零时只设置这个7Ah标记，没有未实现的绘制回调被跨过。
5. 保留 `00672B30` 的双精度位模式 `41615C51C1126E98` 到50h，58h/5Ah
   分别为8/5，然后执行已完成差分的真实无窗口挂链路径。

arena扩容通过恢复的分配策略和真实CRT边界；每次移动在arena callee继续之前
发布到当前上下文 `006BBA54`。适配用一个临时指针和重分配转接明确发布，避免将
`void**`直接别名到C++的uint32全局。页+18C仍保留原上下文缓存规则，切页时更新。

unsupported_state/wrong_context在准入前不转移父向量。准入后，父向量在成功或
allocation_failed时均已消耗。分配器原语必须像真实CRT一样保持当前上下文；
若违反此约定，防御性清理后返回不同的context_changed，不能误当作准入拒绝。

返回对象已经挂入页并拥有真实父子边，但CC仍为零，类型payload仍待记录解码器
填入。这与所选原构造路径一致，不等于已经完成坐标读取、约束求值、完整对象
构造器、页面析构、命令/撤销链或GSP双向开存。

## 原码差分与集成边界

21,297字节测试夹具包含完整 `00441DE0`、实际标签初始化/设置/缓冲/布局子树、
UTF-16比较/复制、向量容量读取及独立原始分发表/常量。完整Listing及地址/文件
偏移/哈希在 `tests/fixtures/minimal-object-construction/`；生产不使用机器码。

oracle调用已分别完成差分的恢复分配、父边建立、默认样式和挂链callees，
这些是共享真实依赖，不重复宣称对其独立验证。实际原标签子树在测试中执行；
中文资源与有界ASCII `#%d` CRT格式化有显式宿主适配。未支持的直接/表中回调
指向立即终止陷阱；所选主类型的真实空回调保持为空，不填成功实现。

43组构造差分比较完整页、全部对象/两个arena缓冲、当前基址、返回状态、x87标记、
分配/扩容/释放记录。覆盖三种构造、数字长度边界、field08两种状态、对象分配失败、
首次子边分配失败及真实callee触发的受控arena搬移。4组拒绝检查未修改状态或
取得拥有权。另在真实堆上以生产偏好/页面构造器建立四对象图，核对内部标签与
genera，再用实际反向解绑/向量释放逐一删除；页面/arena仍显式释放，完整原页面
析构仍是后续任务。

原构造与标签证据位于 `analysis/sessions/object-construction-initialization/`。
