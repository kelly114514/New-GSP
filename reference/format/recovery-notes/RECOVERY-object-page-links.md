# 对象分类环、观察者与最小挂链/释放

完整恢复函数为 `00440CA0`、`00442440`、`00442660`、`004426D0` 和
`00462640/670/690/6E0/730`。生产代码不执行原 PE。

## 布局与来源

- 对象 `+80/+84` 为页面总链的相邻指针，页面 `+110/+114` 为两端。
- 对象 `+90/+94` 为分类环，页面 `+11C+4*category` 为环锚点，
  `+14C+4*category` 是需在移除时失效的缓存。解除后四个链接均用 `FFFFFFFF` 标记。
- 分类来自 `0064E7E8` 主类型行 `+50`，值13是动态分支。kind6取对象
  `+140`；kind15沿 arena `+AC` 第一个父对象递归，并保留原分支的类别调整。
- `00649F20` 的12个DWORD控制排序；仅类别1使用 `+14` 的有符号顺序。
  未指定顺序的原值为 `FFF0BDC1`。点的自由/特殊约束分组和线段的
  genera13/14分组保留原环顺序，不能替换成按编号排序。
- 完整约束行基址为 `00651980`；标志来自 `+24h`，即操作数
  `006519A4 + constraint*70h`。`00651994` 是行内+14h的字段地址。
  `object_page_link_tables.inc` 只含来源明确的两列数据，提取器普通运行核对
  原件；必须显式传 `--write-source` 才会重新生成生产数据。
- 观察者节点16字节：`next/user/callback/removed`。注册调用原 CRT malloc
  边界，而非应用层压力重试策略。通知后重读节点的移除标记和next，按原算法
  延迟清理；清理保留活节点次序。删除全部时每个活节点得到 `(0,user,0)`。
  callback是调用者注册的真实观察者接口，没有默认成功实现或原地址回调。

## 最小生产路径与限制

`attach_minimal_object32` 是 `004426E0` 的显式受限路径，
`destroy_minimal_object32` 是 `00441000(object,remove,1)` 的显式受限路径。
两者没有被计作完整原函数恢复。它们先检查当前上下文和支持条件，遇到尚未
实现的状态在修改前返回明确错误。

挂入支持当前无窗口页面中的新点/线段公共对象：kind1/2、B8和E8为零、
四个页面/分类链接均为FFFFFFFF。after按原约定取有效同页对象、零或FFFFFFFF。
执行通知、修改计数、总链插入、分类环插入和 `+8==1` 的页面计数更新。
此时 `00499790(object,3)` 没有可观察副作用；窗口调度分支由上下文前置条件排除。

释放要求同一无窗口页面、没有活动求值列表（页面+52C=0）、存活子对象、
选择、堆标签/文本缓存、观察者、辅助对象引用或D4特殊拥有权；原生内联短标签允许。
调用真实父子解绑
`00440F60`；默认unlink模式按原 `004427E0` 受限路径摘总链/分类环并更新计数。
whole_page模式选择原remove=0，保持页面总链/分类环及其计数，供逆序整页释放，
不得再遍历已包含释放对象的环。最后用已恢复
`004D5790` 依次释放AC/B0/B4向量，再释放对象。kind1/2的主类型行+28为零，
原函数没有类型析构回调。该状态下 `00482E10`、`00403C20` 和 `00499790`
直接返回，受限实现没有使用成功替身。调用者必须按依赖逆序释放；有活子对象时拒绝。

类型payload读取、其他状态的选择/求值/文本/辅助引用清理、完整对象和页面析构、
完整启动及文档CLI仍未完成。整页受限释放见 `RECOVERY-minimal-page-release.md`。
本模块真实堆集成只证明公共分配→页面挂链→释放，
不代表已恢复自由点/线段/中点的全部构造或GSP双向开存。

## 验证

`object_page_links_differential` 使用原件哈希绑定的19,435字节夹具。原始完整
Listing和重定位清单在 `tests/fixtures/object-page-links/`；原机器码只出现在测试中。
分类、环操作和观察者分别20、114、16个场景；受限挂入12个，释放16个。
比较每次操作后的整页/整对象/arena字节、返回状态、通知顺序和释放次序。
释放场景含真实arena分配建立的共享父点→线段→中点形状的引用图，按子到父顺序
释放，分别检查单对象摘链及整页remove=0，并验证活子对象拒绝时内存不变。
另用实际MSVC堆、真实页面构造器和公共
对象分配器贯通挂入及释放。

受限路径的oracle运行完整原挂入、摘链和析构函数，以及实际原选择、求值和辅助
清理函数的返回路径。未覆盖的外部调用指向立即终止的陷阱，不能返回成功。
其中向量释放使用另行完成差分的恢复实现作为共享依赖，因此本套测试不重复声称
独立验证arena释放算法。原生证据见 `analysis/sessions/document-defaults/` 和
`analysis/sessions/document-lifetime-core/object-destroy.asm`。
