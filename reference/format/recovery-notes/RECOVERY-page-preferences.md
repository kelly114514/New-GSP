# 页面偏好与最小启动输入

完整恢复函数为 `00493B10`（偏好数值正常化）和 `004E0460`（15项默认颜色）。
`initialize_default_page_state32` 是显式的无窗口启动适配，不计作完整
`00493970`、MFC字体注册器或偏好文件读取的恢复。

## 原生布局与算法

偏好块从 `006BF6E0` 开始。页面构造器复制其前FC字节；`+F4` 是单位索引。
`006C0238` 恰好等于该块的 `+B58`，不是另一个零初始化后可直接使用的常量表。
`00493B10` 写入 `+B58=1`、`+B60=DPI/2.54`、`+B68=DPI`；DPI是
`+B50` 的有符号DWORD。按原 `FILD/FST/FDIV/FSTP` 顺序执行，保持调用者
x87控制字的精度、舍入和异常标记。除数原值位于 `006726F0`。

`+114` 下限为22，`+10C/+110` 各自限制在22和该上限之间。最后写
`+B70=2`、`+B74=0064E7E0` 的当前DWORD、`+B78=2`，不覆盖其他字节。

颜色函数读取Windows `COLOR_WINDOW` 及九个原全局颜色值。三分量之和
小于120h时使用白色对比色，否则使用黑色；保留传入COLORREF完整位模式。
九个全局地址依次为 `6AB1B4/DC/D8/D0/D4/E0/CC/E8/B8`（同一6AB1xx范围）。
新环境把这些实际系统/全局输入显式传入；输出的15项顺序与重复值保留。

## 无窗口资源适配

原 `00493970` 前FC字节包含七个DWORD开关、六个22字节字体样式、15项颜色及
末尾七个DWORD。中文 RCDATA128 类别3选择基址3632，其索引72..83对应
RT_STRING3704..3715：`B24/Times New Roman`、`16/Times New Roman`、
`18/Arial`、`16/Arial`、`14/Arial`、`14/Arial`。

适配器根据这些资源初始化全部FC字节，并使用恢复的数值正常化计算三个单位比例。
DPI和窗口背景色由实际宿主提供；无效DPI在修改输出前拒绝。初始九色、除数和
精度常量均有PE地址/哈希绑定；普通提取器只验证生成的 `.inc`，显式
`--write-source` 才会修改生产资源数据。

新适配器定义自己的两项内部字体目录：字体word1为Times New Roman，word2为Arial。
这不是对原程序启动时全局字体编号的断言。后续字体输出必须经
`page_default_font_face32` 映射名字；禁止把内部编号直接当成文件中的字体编号。
任意字体、字体回退、完整MFC字体注册及完整偏好初始化仍未恢复。此适配器只解决
最小页面生产初始化的资源与单位输入，不能代表完整应用启动或完整 `00493970`。

## 验证及限制

326字节原码/常量夹具按原件SHA-256绑定，只在测试中执行。完整Listing位于
`tests/fixtures/page-preferences/`，每个地址和资源payload均由提取器核验。

`page_preferences_differential` 对数值函数运行288组原码差分，覆盖三种x87精度、
四种舍入模式、有符号DPI极值和计时上下界，比较完整偏好块与异常状态。
颜色函数16组差分比较完整输出和边界哨兵，并核对原系统调用的索引/次数。
原系统颜色调用被明确的输入适配替换；未替换应用层算法。

资源提取核对12项实际字符串及初始颜色。集成从真实桌面DC读取DPI和窗口颜色，
运行资源适配→恢复页面构造器→公共对象分配→受限挂入/释放→上下文退出。
该集成没有预填偏好内存；公共对象类型payload、完整页面析构及双向GSP开存仍缺。
静态调查见 `analysis/sessions/page-preferences/` 与
`analysis/sessions/document-lifetime-core/preferences-initialization.asm`。
