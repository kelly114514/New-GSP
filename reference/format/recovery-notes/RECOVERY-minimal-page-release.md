# 最小无窗口页面释放

`release_minimal_page32` 是对原 `004A29E0` 所选路径的显式源码适配，
不计作完整原页析构恢复。生产代码仅调用恢复源码及实际分配器，没有执行原 PE。

## 实际调用链

完整原 Listing 和哈希绑定夹具保留在 `tests/fixtures/minimal-page-release/`，
REA 查询在 `analysis/sessions/minimal-page-release/`。`004A29E0` 使用 EDI 页面参数，
完整范围为 `004A29E0..004A2B1E`；Ghidra 的 `_free` no-return 误标会截断伪代码，
此处以完整原字节和 Listing 为准。

原函数临时切到目标页面，经 `004A3DF0` 复位交互状态、`004CEA90` 清理历史，
从页面 `+114` 沿对象 `+80` 逆序调用 `00441000(object,0,1)`。
这里第二参数为零：真实 `00440F60` 仍解除父子边并递增修改计数，
但不摘页面总链/分类环，也不发送移除通知2或递减 `+39C`。
原函数在释放当前对象前缓存前驱，随后整页丢弃。

所选类型为 kind1/2，主类型行 `+28` 类型析构为空；没有堆标签、文本缓存、
观察者或其他拥有权时，原对象析构只再执行相关空状态分支、通知1、
按 AC/B0/B4 顺序释放向量并释放对象。该分支由
`destroy_minimal_object32(..., MinimalObjectRemoval32::whole_page)` 实现，
已经与完整原对象析构差分，不能用单对象摘链删除代替。

页面通知/清理使用完整恢复的 `004626E0/00462730`，然后释放当前 arena，
将 `006BBA54` 置零，清空当前上下文和页面缓存；若此前当前页是另一个页面，
恢复它的 arena、related 指针和上下文状态，最后释放目标页。
目标页原已当前时，原函数不保存它为待恢复页面；关闭后当前页为空。

## 明确的支持条件

仅允许有效分配器所拥有的无 owner 页面，包含按拓扑顺序挂入的自由点
`constraint/kind/genera=0/1/4`、线段 `2/2/14` 和中点 `1/1/11`。
内联短标签允许。原页创建器、默认偏好适配和最小构造器可生成这些状态。
页面可以是当前、非当前或当前为空；当前页的 live arena 优先于可能因扩容而
尚未刷新的 `+18C` 缓存，避免释放旧地址。

适配在任何切页/修改前检查未恢复状态：GUI选中页、动作、动画、求值、历史、
观察者、延后队列和辅助拥有权都必须为空。对象不能带堆标签、文本缓存、
选择/观察者/辅助引用或 B4 extra。交互 mode 位于原切换范围1..14或延后链非空
也直接拒绝。这些是显式准入限制，没有未恢复 callback 的成功替身。

`HeadlessInteractionState32` 明确保存原交互全局量的对应值；默认构造代表
新无窗口宿主的空状态，不宣称恢复 GUI 启动。实际所选原复位路径为：

- `00402A30`：页面 `+564` 动作链为空，立即返回。
- `004B1110 -> 004A1D80`：切到空GUI页并恢复，延后链为空，清除 flags 的40h；
  mode 不进入1..14时不调用工具处理函数，仍将 capture 单元置零。
- `004A3DF0`：动画与队列为空，清除 flags 的10h。
- `004CEA90 -> 004CEA30`：两个历史锚点均为空，没有副作用。

准入验证是新增防护代码，最多1998个对象，不冒充原算法：检查总链、12类环及
缓存归属、arena 块边界/空闲链、向量唯一拥有权、父边数量、父先子后以及双向边的
重复次数。两个相同端点产生的重复父边仍按原次数处理。
不支持状态、非法图及上下文拒绝均保持内存和全局量不变。
输入须为本工程创建的有效原生分配；这不是对任意指针或原始文件字节的安全解析器。

释放过程不分配内存。分配器禁止重入或改变当前上下文；若违反约定导致后续对象
析构拒绝，返回 `context_changed`，明确表示释放已经开始，不是原子拒绝。
完整 GUI、历史、文本、工具及其他类型页析构仍未恢复；文档读写闭环也未完成。

## 验证与实际集成

测试执行1,163字节完整原页析构、复位及历史 helper 字节。
上下文、对象析构和观察者使用另行差分通过的恢复实现作为两侧共享依赖，
不重复声称本测试独立证明这些算法。其余未恢复调用均立即终止，不能返回成功。

18个场景覆盖空页、自由点、线段、中点、重复端点、共享线段的两个中点，以及
当前目标页/其他页/空上下文。受控真实 arena 扩容后检查 live 基址与旧页面缓存
不同的状态。比较整页、全部对象/arena 字节、每次 free 时的完整内容和顺序、
浮点状态、分配轨迹、最终上下文与交互状态；关闭阶段没有 malloc/realloc。
43个拒绝场景验证未恢复拥有权、损坏链/引用/arena、交互与上下文拒绝的原子性。

实际 MSVC 堆集成从资源偏好建立两个页面、五对象共享依赖图，关闭非当前图页面
并恢复另一页，再关闭最后一页。所有由测试跟踪的真实堆分配归零；这里没有在测试
尾部手工释放 page/arena 填补生产生命周期。
