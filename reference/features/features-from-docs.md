# 几何画板 5.06：文档与资源初步功能地图

本报告仅静态读取克隆目录、解码 README、提取 PDF 文本、核对一页手册图像并列举 JAR 条目。**没有执行 EXE/OCX/DLL/JAR，没有验证运行行为，没有切换 REA 活动目标。**

## 1. 仓库性质与已核实资源

- `sketchpad5/README.txt` 是 GBK 文本，自称“几何画板 5.06 最强中文版”，更新日期 2013-07-18，由金狐工作室收集、整理，版权归原作者。该声明不等于开源许可。
- 非 `.git` 文件共 **1,449**：1,431 个 `.gsp`、6 个 PDF、5 个 EXE、2 个 DLL、1 个 OCX、1 个 JAR，及 README/卸载数据/图标。未发现 C/C++/C#/Java/JS 源文件或构建工程。**这是已安装发行目录/发布资源合集，不是 Sketchpad 原生源码仓库。**
- `Samples/` 有 **1,385** 个 `.gsp`：`4.x实例/` 85、`5.x实例/` 990、`分形艺术/` 310。`Tool Folder/` 有 **44** 个 `.gsp` 工具组。另有根目录 `Sample.gsp` 和 `Support Files/Example Tools.gsp`。
- `README.txt` 宣称默认自动加载 342 个常用工具；手册宣称完整集合有 44 个工具组、810 个自定义工具。**44 个文件已静态核实，342/810 个内部工具尚未解析验证**；工具文件数不等于工具数量。
- 帮助目录实际上是六份 PDF，没有随包 HTML 帮助或 CHM。

## 3. 文件与导入/导出边界

手册 PDF 76–77 的文本与第 77 页截图共同支持：

- 默认保存 `.gsp`；“另存为”下拉框截图列出 **几何画板文档 (*.gsp)、GSP4 文档（兼容版本）(*.gsp)、HTML/Java 几何画板文档 (*.htm)、增强型图元文件 (*.emf)**。不能仅凭相同扩展名认定 GSP4/GSP5 内部编码一致。
- 按住 Shift 打开“文件”，可将“另存为”切为“另存为网页”；手册说会自动复制 `jsp5.jar`。导出 HTML 是获取可读构造描述、进而对照 GSP 二进制的优先实验入口；是否保留全部对象和元数据仍需实测。
- 支持通过剪贴板复制图形到其他软件、粘贴图片到画板。手册提及 PNG 的上下文是**外部截屏/其他软件转图**，不应误写为主程序原生 PNG 导出。
- 手册称 5.06 有 gsp3/gsp4 语言支持，但无法保证更早文档都能打开。这不是已验证的完整向后兼容承诺。
- 多页文档可从当前文档或其他已打开文档复制页面，包括隐藏内容；参数和自定义变换是页内有效，不跨所有页全局共享（PDF 78–79）。
- 手册称中文版“画板课堂链接”“画板交换空间”未开放（PDF 76）。这只是该汉化发行版文档描述，不宜归为已验证可用模块。
- 未找到通用外部脚本执行语言/用户代码 API 的文档证据。“自定义工具脚本”主要指构造步骤视图，不等于 JavaScript/Python 插件。

## 4. 最有价值的逆向入口

### A. 自定义工具脚本视图

使用手册 PDF 33–38 说明脚本视图包含注释、假设（可选）、前提条件、操作步骤、字体调节和操作提示。输入条件可为点、路径、线/圆、函数、度量值。前提条件可重排，并能按标签自动匹配已有对象。双击步骤显示对象属性，右键可操作对象与脚本。

PDF 37 说明可用“下一步骤”“所有步骤”执行构造过程；PDF 80 更直接建议将普通文档制作成临时工具，再显示脚本来查看制作过程。这些是工具脚本行为的文档来源，尚不能替代实际执行证据。

工具文件本身仍为 `.gsp`，一个文件可包含多个工具。默认工具夹与完整 `Tool Folder` 不是同一概念；手册记载旧安装环境默认可为 `C:\Program Files\Gsptools`，不代表此克隆目录已经安装好这些设置。

### B. JavaSketchpad 运行库

静态 ZIP 清点 `Support Files/jsp5.jar`：**151 个条目、143 个 `.class`**。其中 142 个类在 `com/keypress/Gobjects/`，另有根目录 `GSP.class`；MANIFEST 声称由 `1.5.0_16 (Apple Inc.)` 创建。

可读类名提供了较明确的模块线索：

- 基础模型：`GObject`、`Sketch`、`myObservable`、`AffectedDescendents`。
- 输入/构建：`Build`、`parseList`、`exprToken`、`JSP_ExternIO`、`parsingSyntaxError`。
- 几何对象：`FreePoint`、`PointOnObject`、`Midpoint`、`LineCircleIntersection`、`CircleCircleIntersection`、`PolygonByVertices`、`SamplerCurve`。
- 表达式/函数：`Function`、`Parameter`、`variableRef`、`functionEvalRef`、`predefFunc`、`numericConstant`。
- 变换/交互：`Translation`、`Rotation`、`Reflection`、`Dilation`、`AnimatedPoint`、`HideButton`、`ShowButton`、`SimultaneousButton`。

这些类名是已核实的归档条目；归档清单本身不证明实现语义。现有反编译源码和局部差分范围见[Java恢复说明](../recovered/java/RECOVERY.md)；Java库不代表原生程序的全部功能。

### C. 3D、分形、复数工具

`Tool Folder/40 [3d]基本工具.gsp`、`41 [3d]着色工具.gsp`、`42 [3d]旋转.gsp` 是 3D 教程的重点；`43 复数工具.gsp`、`44 分形工具.gsp` 可用于研究复杂计算/迭代。

**3D 教程 PDF 2–3 明确说它是自定义工具，通过中心投影把空间坐标转换成二维图象**。包括坐标系、构造/测量、绕轴/点旋转、遮挡线虚实、面着色、二元函数等。不能因为菜单出现“3D”就认定主程序含原生 3D 渲染引擎。

分形目录的 310 个样例及 344 页《分形艺术程序设计》适合在依赖/迭代与表达式解析明确后，作为复杂样本集；不宜用来推断最小 GSP 格式。

### D. ActiveX 与打包机

实际文件：`Control/AddGSP.dll`、`Control/GSP5.exe`、`Control/gspmsg.dll`、`Control/jhhb5.ocx`；根目录有 `GSP2EXE.exe`、`Sample.exe`。二进制职责需要 REA 进一步确认，不能只靠命名判定语言和调用关系。

README/控件教程描述两类历史控件：`GspForPPT Control` 与 `GspControl.gsp`。属性/标识线索为 `GspFile`、`ShowMenu`、`ShowTool`、`ShowScroll`；叶氏版本另有 `EmbFile=true` 的完全嵌入功能。**文档提及两种控件不代表当前目录实际包含两套**。教程称 Office/WPS 需要 VBA 组件，这是旧版宿主环境说明，并非已验证的当前系统要求。

## 5. 验收场景的来源

文档提供基本构造、HTML/Java导出、父子更新、删除/撤销/隐藏、工具脚本、参数函数、轨迹和迭代的场景线索；控件教程提供嵌入与宿主行为线索。本材料不证明这些场景已执行，实施和验收顺序统一见[总计划](../recovered/PLAN.md)。
